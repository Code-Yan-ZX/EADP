# EADP 追加复现审计（2026-10-09）

本次继续检查 EADP_amp 最新多模型、多数据集结果。结论是：**仍有确定的项目错误和已量化的协议差异，而且尚未把全部本地 EADP 基线复现齐。没有证据表明所有结果统一少了两点，也不能承诺当前补跑结束就达到论文水平。**

证据时间为北京时间 2026-10-09 01:14–01:21。官方发布代码固定在 `e1a08801461c181871b9ff1cb0803b8e9966f083`；论文主表以 [EADP v1](https://arxiv.org/html/2607.02484v1) 为准。所有新检查使用独立目录和 CPU，未修改现行生产算法、冻结的 GPU 队列、生成协议、预测、评分或运行环境。

## 新发现及因果边界

| 项目 | 证据与影响范围 | 处理状态 |
|---|---|---|
| **MMBench-CN 漏传 `--lang cn`** | 官方 v1.5/NeXT 脚本明确指定中文，旧项目脚本遗漏，原生入口默认英文。4876 条 LLM 答题指令全部不同；剪枝 guidance 和保存的 prompt 字段不受该参数影响。涉及两模型 × 三预算的旧 AZ 完整结果。 | 确定的项目协议错误。现行 wait-only 队列保留英文以隔离同步影响，**不会自动修好语言参数**。独立修正方案见 `correction_controls_proposal.json`，未注册或启动。准确率效果未测。 |
| **MMBench 题集版本不同** | 官方发布脚本指定 EN20230712/CN20231003；当前使用 V11。EN 旧集4377行/1176组，V11为4876行/1292组，共有950个基础ID，其中31个题目/选项/答案有变化，16个答案字母不同。 | 版本差异确证。V11 内部同题集对照仍有效；论文实际题集文件尚未取得，不能称已经与论文同题。仅按基础ID重评不能消除输入差异。 |
| **VizWiz 评分公式不同** | EADP 发布 scorer 使用 `min(match_count/3)`，基准官方 scorer 使用逐标注者留一平均。6份完整4319题的相同预测，发布代码分数比当前官方分数高 **1.391–1.473个百分点**；NeXT AZ128 为59.254457% /60.716215%。 | 当前官方评分正确，保留为主结果；发布代码评分仅作有标签的辅助审计。论文究竟用了哪个 scorer 未确认。无需因评分差异重新生成答案，不能据此假设 TextVQA 的2.204点残差被解释。 |
| **VizWiz 生成入口不同** | 旧项目 `model_vqa` 保留单词回答指令作为 guidance、上限1024；发布的验证 loader 移除该指令、上限128。全部4319条 guidance 不同，LLM问题文本相同。 | 需要独立协议对照，现行同步重跑保留旧 recipe。准确率效应未知。 |
| **任务默认 α/β 不同** | 发布脚本 β默认1，当前主要剪枝实验β2；POPE α默认1 vs本地0.5，VizWiz验证 α默认0 vs本地0.5。其他检查任务 α0.5相同；MMVet本地β1也相同。 | 22个官方入口已逐一记录。脚本默认值不等于作者论文实际参数。已有 NeXT Text K32 β1 完整控制注册待运行；没有参数搜索，也不按最高分反推论文配置。 |
| **我们方法的 NeXT Completion 跨裁剪图** | 预注册要求逐 crop，实际按整幅图的 `split_sizes=[5]` 将五个 crop 展平后分配，允许跨 crop 合并。CPU构造可证明输出不同。 | 确定的 AZ 实现/预注册偏离，**不能解释 EADP 基线残差**。独立逐 crop 适配器与16项CPU检查已通过；未安装到冻结实验、未注册GPU、准确率效应未测。 |
| **Qwen HallusionBench 生成来源记录不闭合** | legacy E256 的 meta 保存 bank SHA 与当前完整 bank SHA 不同；同批另六任务一致。resume入口只在meta不存在时记录SHA，可能留存旧记录，但缺乏生成时证据确认。 | 完整预测和官方分数保留，单独标注来源 caveat；不能认定分数错，也不事后伪造正确生成身份。 |

## 已排除和仍不能定性的原因

NeXT 不剪枝 TextVQA 完整5000题为 **60.370%**，论文 **60.3%**；v1.5为58.226% vs58.2%。这说明“整模型统一低两点”的判断不受当前证据支持，仍不能排除剪枝分支的配置、输入或执行问题。NeXT Text K32旧官方入口 EADP51.996% vs论文54.2%的 **2.204个百分点**残差，不能在新完整控制未结束时宣称已经恢复。

- 两模型共用的独立CLIP336权重文件1,711,974,081字节SHA匹配官方HF revision `ce19dc912ca5cd21c8a653c79e251e808ccabcd1`，7个配置/分词/预处理文件也匹配；13个扩展核心/入口文件与固定官方代码逐字相同。此前NeXT语言模型/投影权重身份核验沿用已有证据。本次没有核验v1.5全部语言模型payload，也没有把文件一致当作运行时对象/作者revision已证明。
- POPE8910题与LLaVA官方包逐字一致；LLaVA指向的POPE旧发布三组原GT确为2910/3000/3000，所有问答身份、顺序与标签一致。random的90题不是本次项目漏生成，保留用户已确认的8910题，无需为这个问题补90题。
- GQA12578题和GT身份、题目、图名全部一致；MME2374题与官方包一致，历史162条GT错误已经CPU重评，不因标签问题重复生成。
- MMBench原生生成上限1024与EADP、上游LLaVA相同，不能把通用loader128误套到MMBench。
- SQA当前2017图像题严格匹配官方包CQM-A；发布脚本指向作者未提供的CQM-I，不能猜造文件后称论文身份一致。
- 6项依赖版本与发布requirements不同，但无准确率影响测量。RTG只用文本首段的行为确证（TextVQA881/5000题存在多段），原方法没有明确多段映射，暂不归为确定bug。两者都未混入现行方法修改。
