## 4. 研究目标与结论边界

继续以可部署的视觉 token 压缩/剪枝方法为目标，是否采用单模块、组合模块、merging 或其他结构由证据决定，不强制“A+B”。推理需 forward-only，离线训练可用梯度。评价必须包含真实下游生成/指标和真实效率，proxy 不替代最终结论。

数据来源合格不等于比较条件合格。legacy/native、DeepStack/mRoPE、模型、预算、题集版本、提示词、生成长度、同步修复和评分公式不同，都要明确记录。论文数字和本机数字分开；本机有同设置基线后才能做受控方法差。历史逐格最高值只能作历史查看，不能当作一次统一运行的平均分。

MME 对 LLaVA 为感知分、对 Qwen 为感知+推理；MMBench 循环组数不等于旋转行数；POPE random2910 是旧版保留的实际题集。不能通过换指标、补抄数字或自动调整超参弥合论文差距。
