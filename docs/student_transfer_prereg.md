# 冻结学生的跨数据集验证：2026-11-12

用户授权修改评测并实际启动。本轮只评估已训练的基础 bag_rank，不进行新训练、teacher 构建、目标数据集适配、测试选 seed 或测试调参。原 paired_pruning 代码、协议和模型保持不变。

## 固定方法与数据

来源：`Qwen_vl/outputs/paired_pruning/run_20261111/` 的三个 validation-selected bag_rank checkpoint，seed 11/23/37，全部报告。Qwen3-VL-8B-Instruct 原生 SDPA、V 与三条 DeepStack 同索引、原始三维位置；视觉输入1024、剪枝后256；R-res512直接产生原生256。对照为 full、EADP facility B1、block8 B2、R-res512，共7臂。

三个本地公开集合全部原始行：DocVQA_VAL 5349、TextVQA_VAL 5000、OCRBench 1000。预计79443条 QA 输出；不因完整模型错误、截断、题目类型或先前预测删题。源TSV与隔离PIL重编码图像记录哈希，保持仓库VLMEvalKit的默认图片保存方式。

当前学生使用的 DocVQA TRAIN fit128父文档/384题、val24/72用于训练与选点；两者均纳入跨集合重合审计。报告官方完整集合，以及排除父文档/图片字节/源或输入RGB精确重合的子集。另报告保守排除dHash64 Hamming≤3且宽高比差≤3%的嫌疑子集；该启发式不证明排除所有近重复、裁剪、重编码或模板相似。历史项目曝光仅标记，不按历史正确率挑题。本项目已有这些集合的历史评测，因此不得把本轮称作项目从未触碰的盲测，也不能保证底座预训练未见。

## 推理与指标

所有臂相同图片、问题、Qwen3原生简短VQA提示、greedy、正常EOS、最多128个新token。学生的问题序列保持原训练方式：question+原suffix，add_special_tokens=True，bf16完整token embedding，不做均值或静默截断。所有问题先做CPU长度检查，超过256显式报错。

推理函数仅接收图像路径/哈希、数据集名、题号和问题；人工答案只在生成完成后计分。每题可在高分辨率臂间共享同一次新鲜视觉编码，但不跨题复用，所有生成使用独立KV。R-res独立处理图片。禁止将QA共享特征耗时当部署时延。

DocVQA使用本地VLMEvalKit ANLS，TextVQA使用其10人答案共识分数（保留重复注释），OCRBench使用其类别匹配规则，数学类别去空格并区分大小写。冻结三个原评分源文件并以纯函数测试核对。每个seed独立报告，另报均值/范围、相对B1/B2/R-res按父文档或独立图像配对bootstrap 10000次的95%区间。区间不做多重比较校正，不能解释为所有设置必胜。

## 效率和门禁

每集合固定12张不同输入图像，按图片SHA256排序、每图按题号选第一题，从无精确训练重合子集选取。名单在任何目标预测前冻结，不按答案或效果挑选。每臂每图每cap预热2次，3个配对block随机臂顺序，cap为1和16：共1512次正式计时。每次重新图片处理、视觉编码、选择和生成，不复用图片或KV；计入学生前向，模型加载不计。停止于原生decoder同步完成、后置位置/哈希审计之前。只在计时强制忽略EOS，QA保持正常EOS。该结果是单A40、单请求时延，不是服务吞吐或多硬件结论。

CPU检查通过后冻结新源码、清单、原训练来源、三模型哈希、底座metadata及weight stat、指标源、预处理及计时名单。GPU先检查各集合官方prompt一致、原生全保留stock identity、四流/两问题视觉一致、七臂共享与fresh输出/选集/位置一致、学生正常EOS、真实预算和无参数梯度。不用目标准确率决定门禁。

门禁后先做多图计时，再完整QA，最后审计报告。SQLite逐条提交，可续跑但禁止替换已有输出；异常记录并退出，不静默减少分母。冻结后改源码或协议必须新建run目录。首轮任何失败保留日志、状态及门禁产物。

## 解释与下一步

本轮验证当前checkpoint在未参与学生训练的公开任务上的有效性和时延，不自动完成新颖性论证。若泛化收益稳定，下一步才进行同结构、同数据预算的teacher/训练目标对照，以及与最近学习式方法的公平比较。若跨域结果不支持，则不再把当前版本作为已验证通用方法推进，也不据单轮结果否定一般梯度监督。

首轮 `run_20261112/` 在加载GPU门禁辅助模块时因旧脚本的 sibling `oracle` 导入路径缺失退出；尚未产生任何目标QA或计时。失败日志、状态、冻结和当时源码快照保留。修正导入路径后使用新冻结目录 `run_20261112_v2/`，同一原始manifest和权重，未按目标效果修改任何参数。

运行：`CUDA_VISIBLE_DEVICES=0 bash Qwen_vl/scripts/student_transfer/run.sh`，默认输出 `Qwen_vl/outputs/student_transfer/run_20261112_v2/`；状态 `status.json`，日志启动时指定，报告 `evaluation/report.md` 与 `report.json`。
