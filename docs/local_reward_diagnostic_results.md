# LayoutLite 局部奖励诊断：没有获得推进训练的信号

2026-11-08；分支 `codex/visionzip-binding-oracle`，起点 `a724122d`。

本轮已完成32个真实独立文档、192条OCR输出。正式判定为 **HOLD_INSUFFICIENT_INFORMATION**：关键比较仅有5个独立文档、10个方案对，未达到预注册的12文档、24对门槛。困难片段奖励的点估计也没有优于整页或局部均值奖励，因此目前不推进这版 tail20 的训练。这个结果不等于证明一般的局部奖励无效。

## 实验实际做了什么

- 使用官方 FireRed-OCR（Qwen3-VL-2B）和公开 LayoutLite `firered_600.pt`，没有训练或修改底座参数。源码固定 `7e398a2`，底座固定 `7bf5e9d`；完整哈希保存在运行清单。
- 官方源码依赖 Transformers 5.6；执行适配使用本地4.57.6的原生视觉与文本网络，只提取原始评分头及OCR提示词。4级评分特征、主特征、3条DeepStack和原生mRoPE均独立核查。
- 32个新的DocVQA TRAIN父文档，含80个预先选定的人工数值QA。排除前轮文档及历史fit roster；按原有注释、唯一银标定位和40–450个OCR词筛选，没有按模型错误挑页。额外16页候补未使用。新父文档不等于未见版式或官方测试集。
- 每页固定5个等预算方案：评分Top-K，以及4个固定种子的Gumbel-Top-K，均保留 `round(0.5N)` 个token。全保留输出仅作teacher参考。这个动作池不是原方法的两簇阈值推理复现，也不是本项目8B、1024→256设定。
- 对同一完整转写计算整页奖励、归一化整页奖励、片段普通均值、长度加权均值、最差20%片段均值。片段由teacher按行、最多64个归一化字符划分，不使用QA答案定义片段或权重。
- 独立终点是原有人工答案是否仍出现在转写中，保留小数点、前导零和数字边界。这是**证据覆盖代理，不能当作实际QA准确率或字段绑定能力**。FireRed在面板外普通QA smoke为0/6，仍输出OCR，故没有启用真实QA终点。

所有生成均为greedy，统一上限2048。全保留V/三DS、prefill及下一步logits逐位一致；原生8-token生成与串行一致，五方案批处理与串行16-token前缀一致。串行吞吐预跑已归档作废，正式32页统一重跑，full串行、五压缩方案同页batch5。正式生成耗时1298秒；GPU进程已结束。

## 产出和结果

192/192输出完整，无重复或待补项。2页完整参考截断，按协议排除，剩30页；全32页的完整OCR覆盖72/80个人工答案，30个有效页面提供70个可保留答案目标。压缩输出共7条截断，主分析保留，并另做所有方案都未截断的敏感性分析。

主比较限定为整页奖励差不超过0.01、但人工答案覆盖率不同的方案对。下表先在文档内平均，再按独立文档bootstrap，不能把10对当作10个独立文档。

| 奖励 | 与独立证据覆盖排序一致率 | tail20相对差值，95%CI |
|---|---:|---:|
| 整页原始奖励 | 90% | −40pp [−90,+10] |
| 整页归一化奖励 | 85% | −35pp [−85,+15] |
| 局部普通均值 | 80% | −30pp [−80,+20] |
| 局部长度加权均值 | 85% | −35pp [−85,+15] |
| 最差20%片段 | 50% | — |

样本只有5文档/10对，以上是描述性点估计，不能据此宣布显著负效应。包含全部覆盖分歧的辅助比较为10文档/46对：整页81.7%、局部均值78.3%、tail20为73.3%；tail20相对局部均值为−5pp，95%CI[−17.5,+5]pp，仍没有正收益证据。32/128字符分片及反向对齐的预定敏感性也没有给出正向点估计。

离线按奖励从同一五方案中选一个，30页平均证据覆盖为：整页、归一化整页、两种局部均值均98.33%，tail20为96.67%。差值−1.67pp，文档bootstrap95%CI[−5,0]pp。**这不是部署或训练后的性能差值。** 固定Top-K已保留68/70个答案；这个50%保留率、紧凑数值页面设置可观察的遗漏有限，是信息量不足的一个实际限制。

## 可核查的反例与质检

`ynxh0227_4` 的原图右栏清楚写有 Calcium Carbonate = **181.1**。整页奖励选择的方案保留该数值；tail20选择的方案漏掉右栏数值，tail评分却更高（0.71875对0.6875）。原始提示、答案、局部转写和分数保存在 `counterexample.json`。这是事后解释性反例，没有用于改定义、挑页或重算统计，不能单独证明普遍机制。

固定种子抽取的5页独立复核还发现：断行连字符规范化、HTML表格重组、去除teacher重复内容，以及纠正teacher错误，都可能被文字一致性记成损失。数学编辑计数通过核验，但“字符差异”与“真实证据受损”并不等价。不能从这批例子声称所有奖励错误都来自格式，或事后删除这些页面。

完整性审计最终PASS，覆盖冻结哈希、源图/源parquet、五随机动作重放、实际V/DS长度、原生位置、EOS/截断和批处理。审计脚本首次有参数命名冲突，修复后重跑；初始失败记录单独保留，没有改预测或冻结实验设置。

## 决策

暂停这版“直接优化最差20%转写片段”的训练投入。当前既未证明整页奖励存在足够普遍的关键误排序，也未显示tail20能修复它。一般的局部证据保全、在更强压缩下的行为及真实QA效果仍未得到有效验证；后续若继续，需要另行设计有足够真实失败、且能区分OCR参考噪声的实验，不能靠调尾部比例或放宽本轮信息门槛得到正结果。
