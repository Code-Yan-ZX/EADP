# Forward-only student pilot: frozen protocol

2026-11-09. Prepared before any new-panel model-generated teacher labels, student fits, or test answers. This is a small exploratory DocVQA TRAIN experiment, not an official benchmark or evidence that the model never saw these documents in pretraining.

## Question

Can a deployable scorer with only an image and question predict useful spatial-token rankings from the previous experiment's answer-conditioned gradient teachers? Compare four teachers **with identical student inputs, architecture, parameter count, data, optimization and random seeds**: `magnitude_v`, `magnitude_joint`, `signed_v`, `signed_joint`. This isolates teacher labels, not the causal effect of student input streams. Qwen3-VL-8B, native 1024 merged visual tokens to K256, with V and all three aligned DeepStack rows and original 3-D positions retained for each selected index. Earlier legacy teachers and student weights with incomplete DeepStack/position handling are not used.

## Independent data and no leak

From the local original DocVQA TRAIN annotations, deterministically select 120 fit, 16 validation, 32 held-out test and 1 development parent; if insufficient disjoint eligible numeric parents, a documented 96/16/32/1 fallback is permitted only at data-building time. Exclude all VAL and previous project panel/fit parents, including both recent oracle and calibration panels/development pages. Each parent supplies one preselected original numeric QA and source image; confirm unique parent/image bytes across all splits and against old panels. Sampling uses annotations/hash order only, not model outcomes. Preserve all answer aliases and the original question and source hashes. Keep every selected question, including teacher errors and truncations, in its primary denominator.

Only fit and validation teacher labels enter training. Test is never used for optimization, stopping, checkpoint selection, normalization, or arm/seed selection. Cache target/feature files and provenance per question; test teachers may be generated only after all student checkpoints and training records are frozen, and remain label-aware diagnostic references. No gold answer, teacher score, loss, backward, or any validation/test label is available to the inference scorer. Input signature is only current image's four native merged feature streams and the question text's native embedding mean. Physical feature order is V,D1,D2,D3; any question-dependence comes from text, not answer alias.

## Teacher, student and training

For each fit/validation question calculate one native full1024 DS-on answer-only NLL backward (first original alias, no appended EOS, stock 3D positions); gradients only on four merged leaf inputs. Four maps use precisely previous native definitions: `magnitude_s=sum_d |g_s*x_s|`, `signed_s=-sum_d g_s*x_s`, joint=sum of the four *raw* maps, with float32 reductions and stable index tie-breaking. No answer-conditioned teacher is part of deployment. Save all teacher maps, actual NLL/targets, source/revision, no filtering for teacher accuracy or near-zero loss.

The same token-local lightweight four-stream+question model and same dimensions are used for all four labels. Each token stream is per-token RMS-normalized, with four log-RMS scalars preserved; the question mean is RMS-normalized. Linear projections and a fixed 64-wide nonlinear readout score tokens; trainable parameters and exact operation order are frozen in the source before teacher extraction, not adjusted after results.

Rank teacher values stably. Use Top256 membership BCE with positive weight 3 plus 0.5 times margin-1 pairwise ranking of Top32 against ranks 257–1024, Top32 weights proportional to 1/(rank+1) normalized to mean 1. AdamW lr=0.001, weight decay 0.0001, batch 8, 900 updates per arm, seeds 11,23,37 with matched data order for each label at the same seed. Every 30 updates evaluate validation teacher Top8 recall@256; save the highest, ties choose earliest. All 12 checkpoints are subsequently evaluated; never choose a seed/arm using test QA or proxy, and do not apply a proxy threshold to suppress downstream generation. Fixed configuration is a pilot, not a searched optimum.

## Endpoints and controls

Predeclare real greedy generation with normal EOS, at most 32 tokens, numeric exact with all original aliases as primary, official DocVQA ANLS/literal exact secondary. Compare all students to native B2, native R-res512, fixed-seed random K256 and full1024 on the exact same 32 held-out questions, plus compare matching-seed magnitude_joint versus magnitude_v and signed_joint versus signed_v. Report every seed, mean/range across seeds, per-document paired rescue/break/ties, and paired 10,000 shared-parent percentile bootstrap intervals seed 20261109. The 32-question pilot and multiple exploratory comparisons limit inference; a degenerate interval is not equivalence. Report all samples, EOS/truncation, generated texts and aliases. With labels generated after freezing checkpoints, teacher top8/32 recall@256 and K256 overlap are secondary. Full teacher-selected QA is a clearly separate answer-aware reference, not a trained student, strict hard-deletion oracle, or deployable accuracy.

Time end-to-end forward-only references and one fixed preselected seed (11) per student on the independent development page: 3 warmups per arm, 10 paired rotated-order blocks, fresh preprocessing, native vision, question embedding, selector, prefill and first-token choice, and fixed 16-token ignore-EOS end-to-end; model loading excluded and score/selector and memory recorded. One page is not a latency distribution. Report offline teacher tokenization/vision/forward/backward/ranking, storage and train time separately. Never claim student selection has teacher-oracle accuracy, or time the gold-selected set without paying gold cost as deployable TTFT.

## Gates and failure handling

Before training labels, run the established native multistream CPU+GPU gate on the independent development page, including stock and teacher position/DS/gradient checks and capacity. Freeze data/source/model/gate hashes and rendered fit/val prompt and gold token IDs before first label. Confirm image/parent disjointness, no teacher/answer input to student, stable K256, trained-vs-live input normalization and selection parity, full V/3DS/position/cache on each student, repeat identical image/question with changed answers, and finite loss/updates. Preserve failures and source hashes. OOM, missing QA or operational failures are pending failures, never silently dropped/wrong or replaced. Re-gate any source change after freeze and record the deviation; do not use test outcomes to tune any element.
