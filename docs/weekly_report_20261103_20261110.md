# 视觉 Token 剪枝研究周报

**汇报周期：2026 年 11 月 3 日（周二）—11 月 10 日（周二，含当日）**  
**研究主题：EADP 复现与视觉 Token 压缩方法探索**

## 一、本周工作概况

本周围绕 Qwen3-VL 的视觉 token 剪枝，完成了 DeepStack 对照、位置编码与多层特征机制分析、强基线比较，以及多种方法改进尝试。针对一版在小样本上表现突出的蒸馏学生，进一步完成了 DocVQA 验证集全量评测。

**目前最重要的结论有三点：**

1. 在本机 DocVQA 同配置对照中，为剪枝路径补回对齐的 DeepStack 特征后，EADP 从 **61.17 提高到 67.90 ANLS**；但其作用随任务和位置编码变化，不能把该增益直接推广到所有任务。
2. 同为 256 个视觉 token，降分辨率基线 R-res 在 DocVQA 全量上达到 **80.31 ANLS**，高于本轮 EADP 适配及学生模型；但在 TextVQA 小面板上并不占优，方法不能只在单一任务判断。
3. 梯度教师蒸馏的学生在 32 道数值题上曾达到 **31/31/32**，但在 5,349 题全量测试中为 **66.09/59.82/67.52 ANLS**，未复现小样本的明显优势。当前还没有可确认优于强基线的最终方法。

上述工作分布在当前工作区和 V2 归档工作区；本文按研究内容组织，不把不同位置编码、提示词、指标或样本的分数混作同一实验。

## 二、DeepStack 与位置编码：先建立可信基线

### 1. 完成 DocVQA 全量 DeepStack 对照

在 Qwen3-VL-8B、DocVQA 验证集 **5,349 题**、视觉 token **1024→256** 的设置下，对同一方法、同一选点分别关闭和开启 DeepStack：

| 方法 | DeepStack 关闭 | DeepStack 开启 | 差值 |
|---|---:|---:|---:|
| EADP | 61.17 | 67.90 | +6.74 |
| DivPrune | 55.78 | 63.62 | +7.84 |
| CDPruner | 53.04 | 59.60 | +6.55 |

指标均为 ANLS。该组使用旧的紧凑 1D 位置处理，与后续使用原始三轴位置的实验不直接拼表比较。三种方法收益差的差中差区间均跨零，不能据此认定某一种方法对 DeepStack 更敏感。补回模型原有 DeepStack 功能属于基线和实现修正，不能作为新剪枝算法。

16 题、每侧一次、固定生成 32 token 的小样本速度对照中，EADP 开启后平均多约 4 ms/题；该差值小于测量波动，暂不能作为稳定的开销结论。[DeepStack 汇报](../../EADP_v2/docs/versions/v2/eadp_deepstack_experiment_report_20261103.md) · [三方法对照](../../EADP_v2/reproduction/20261103/qwen_other_methods_ds_pair/background_completion_20261103/comparison/RESULT.md)

### 2. 完成位置编码、特征注入与预算消融

在 DocVQA、TextVQA、AI2D 各 **128 题**的开发面板上，固定 K=256，完成“紧凑 1D / 原始 3D 位置”与“DeepStack 关闭 / 开启”四臂对照，共 **1,536 次生成**。使用原始 3D 位置时，开启 DeepStack 对 DocVQA 的配对差为 **+7.17 点**；TextVQA 为 **−0.94 点**，AI2D 为 **0 点**。后两者区间跨零，不能据此宣称没有作用或严格等价。这些是探索性开发结果，区间未针对全部比较做多重校正，AI2D 采用本地确定性选项匹配。[四臂结果](../../EADP_v2/reproduction/20261104/deepstack_compression/e1/e1full001_score/RESULT.md)

进一步完成三路 DeepStack 的开关、位置错排和均值广播干预，以及 K=128/256/512/1024 预算对照。三条预设留一层关闭比较的区间均包含零，**不能据此认定某一路可以无损删除**。DocVQA 上，开启 DeepStack 后较小预算仍低于下一档关闭 DeepStack 的质量，说明不能简单把特征注入等同于多一档 token 预算。[层与对应关系](../../EADP_v2/reproduction/20261104/deepstack_compression/e2_e3_analysis/score_run001/RESULT.md) · [预算对照](../../EADP_v2/reproduction/20261104/deepstack_compression/e4_analysis/score_panel003/RESULT.md)

### 3. 引入降分辨率强基线

在相同开发题目、每任务 128 题的对照中，R-res 以 512 分辨率产生 256 个视觉 token，其相对 EADP K256 的结果如下：

| 任务 | EADP | R-res | R-res − EADP |
|---|---:|---:|---:|
| DocVQA | 67.85 | 80.98 | +13.14 |
| TextVQA | 80.78 | 72.81 | −7.97 |
| AI2D | 82.03 | 82.03 | 0.00 |

这表明降分辨率是必须纳入比较的强基线，但优势具有任务依赖性。该面板属于探索性结果；两者输入分辨率不同、相同 token 数不代表相同计算量，且跨运行比较没有逐次归档完整有效生成配置。[R-res 对照](../../EADP_v2/reproduction/20261104/deepstack_compression/e6/rres_k256_full_analysis_v2/RESULT.md)

## 三、针对强方法和失效机制的探索

本周对几个具体假设进行了真实生成或代理诊断，结果如下：

| 探索方向 | 做法与主要结果 | 当前判断 |
|---|---|---|
| 语义差异挖掘 | 对数字编辑对筛查，完整模型验证通过的 101 对中，B2 在 62 对至少一侧答错、18 对出现同答案塌缩；六组训练对照在保留集均为 0/32 | 能挖出真实盲区，但当前训练载体严重失效；不能声称闭环方法有效，也不能否定一般难例挖掘思路 |
| VisionZip/PPE 字段绑定 | 56 个完整模型验证通过的文档对中，限制跨区域合并与同 anchor 对照均为 22/56 全对；单问从 149/224 提高到 156/224 | 有局部正向信号，但未达到预设主指标；暂停该版区域约束训练 |
| LayoutLite 局部奖励 | 32 个文档的 OCR 动作排序诊断；符合主比较条件的仅 5 个文档、10 对，未达预设信息量门槛 | 信息不足；这是 OCR 字面证据覆盖代理，不能写成真实 QA 或训练收益 |
| CatchUp 候选修正 | 16 道数值题上，两阶段现有适配基线 2/16，新配置 0/16 | 当前配置不支持推进；基线偏弱且样本小，不能否定原版方法或一般重排序 |
| VisionZip 注意力校准 | 32 题上，零偏置/普通簇大小/相似度有效簇大小分别为 20/21/19 题 | 本版有效簇大小没有得到收益；显式 mask 本身也会影响输出 |

详情分别见 [语义差异挖掘](cf_mining_pilot_results.md)、[字段绑定](binding_oracle_results.md)、[局部奖励](local_reward_diagnostic_results.md)、[CatchUp 适配](catchup_rerank_results.md)、[注意力校准](attention_calibration_results.md)。这些都是对具体实现与设置的判断，不能扩大为对整个研究方向的否定。

## 四、从梯度教师到前向学生：小样本成功未能推广

### 1. 离线教师与小样本学生

在新的 DocVQA TRAIN 独立父文档上，先用标准答案和梯度构造离线教师。32 题探索中，magnitude 标签的主视觉流教师和四流联合教师均为 **31/32**；signed 标签从主流 **22/32** 到联合 **27/32**，但交互区间跨零。该教师依赖答案和 backward，只能作为离线诊断，不能作为可部署方法或严格上界。[多流教师结果](multistream_oracle_results.md)

随后用 **120 个父文档训练、16 个验证、32 个测试**，训练四组教师标签、每组三个种子的前向学生。magnitude V 教师学生三个 seed 分别为 **31/31/32 题**，同面板 B2 为 **22/32**、R-res 为 **19/32**。这里的“V 教师”指离线标签来源；学生实际输入仍包含主视觉流、三路 DeepStack 与问题。该结果仅来自小样本数值 QA，不能直接推广。[学生实验](student_distill_results.md)

### 2. DocVQA 全量复测

对前述三个 magnitude V 学生 seed，以及完整模型、B1、B2、R-res，共七组各跑完 DocVQA_VAL **5,349 题**，合计 **37,443 条生成**。使用统一 Qwen3 VQA 提示词和 DocVQA ANLS：

| 方法 | 视觉 token 数 | ANLS |
|---|---:|---:|
| 完整模型 | 1024 | 94.54 |
| R-res512 | 256 | 80.31 |
| B1：EADP 分数 + facility | 256 | 72.12 |
| B2：EADP 分数 + block8 | 256 | 68.31 |
| 学生 seed 11 | 256 | 66.09 |
| 学生 seed 23 | 256 | 59.82 |
| 学生 seed 37 | 256 | 67.52 |

相对 B2，学生 seed 11/23/37 分别为 **−2.22 / −8.50 / −0.79 点**。最后一个差值的按 938 个源父文档配对 bootstrap 95% 区间为 **[−2.46, +0.86]**，不能认定与 B2 有明确差距；其他两个种子的区间均低于零。三个种子均低于 B1 和 R-res，存在明显种子波动。

七组覆盖完整，独立逐题计分与正式 ANLS 一致；少量达到 128 token 上限的回答仍保留在主分母。小样本与全量使用的题型、提示词和指标不同，因此**只能确认优势没有在本次全量设置中复现，不能单独归因于某一个因素**。训练、验证和测试与全量集的父文档及精确原图像素无重叠，但本项目此前看过部分 DocVQA_VAL，也无法排除基础模型预训练或有损重编码的潜在重叠。[全量结果和配对区间](student_full_results.md)

## 五、工程与实验规范

- 对 Qwen3-VL 剪枝入口、DeepStack 特征及三维位置进行了同输入对照和门禁检查，避免把实现差异误当方法收益。
- 建立按父文档、原图字节和精确像素去重的数据划分，并冻结样本、参数、代码与 checkpoint；保留未截断与截断敏感性分析。
- 完成逐题预测持久化、失败记录及断点续跑；对全量实验执行独立计分、覆盖和冻结一致性核验，并按父文档配对计算不确定性。
- 将原始产物、预注册协议和独立审计结果分开存档；小样本、离线 oracle、训练阶段和可部署推理的结论分别标注。

## 六、下一步计划

1. **分析全量失败样本。** 按问题类型、答案形式、图像内容和版面特征比较学生、B1/B2 与 R-res 的共同失败及互补题，抽取可核查案例，定位证据遗漏与回答错误的关系。
2. **验证差异来源。** 在同一批预先固定的题目上控制提示词和评分方式，检查小样本结果与全量结果之间哪些差异可以复现；避免把相关性直接写成原因。
3. **针对机制提出下一轮方法。** 若失败集中于图像证据丢失，再设计对应的选择或训练目标，并以 R-res 与 EADP 的同预算结果作为必要对照；不预设最终结构必须拼接模块。
4. **扩展验证范围。** 候选方法通过受控试验后，再检查 TextVQA、OCRBench、不同 token 预算与真实端到端耗时；继续区分方法自身收益和协议差异。

目前未完成一个在多个任务上稳定优于强基线、且具有明确端到端资源优势的可部署方案；下一阶段以定位失败原因和形成可验证的新假设为主。
