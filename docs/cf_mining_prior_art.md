# 当前压缩器驱动的语义差异挖掘：相关工作与贡献边界

核验日期：2026-11-08。下面依据直接阅读的论文正文记录机制；未执行穷尽检索，也不据此认定候选方法已经具备论文新颖性。此文不报告新实验结果。

| 工作与已核验版本 | 论文中的具体机制 | 与候选方向的重合及边界 |
| --- | --- | --- |
| [ETC，2606.00543v2](https://arxiv.org/html/2606.00543v2)，§3.2–3.5 | 用指令到视觉的 cross-attention 近似任务相关统计量，通过交叉熵与变分信息蒸馏训练 bottleneck 压缩表示。 | 任务感知、保留答案相关证据已有明确先例；所述算法不以当前压缩器无法区分的语义编辑对作为挖掘对象。 |
| [VC-OPD，2610.14939v1](https://arxiv.org/html/2610.14939v1)，§3.2–3.4、§4.6 | 学生先生成当前策略下的回答轨迹；教师分别在原图和受损图上评分，用教师概率差为蒸馏 token 加权，并归一化总权重；默认反事实构造是 patch dropout。 | 反事实蒸馏、视觉依赖加权与 on-policy 更新已有先例；其反事实主要削弱视觉证据，所述算法没有搜索具有不同正确答案、且教师两侧均正确的最小语义编辑对。 |
| [CIRA，2609.35002v1](https://arxiv.org/html/2609.35002v1)，§3、§4、§6 | 明确定义完整视觉输入正确而压缩输入错误的 compression-specific failure。攻击仅访问视觉编码器，通过 token 优先级操纵及被移出证据的表示保持来构造扰动；TCS 防御汇聚平移视图的 token 排序。 | 压缩特有失败的定义和成对归因已有先例；攻击优化不访问实际部署的压缩器、问题或标签，防御也不是更新压缩器后重新挖掘语义差异的训练闭环。 |
| [EvoComp，2604.17087v1](https://arxiv.org/html/2604.17087v1)，§3.2–3.3 | 进化搜索降低 VLM 输出损失的 token 保留子集，结合语义分组产生标签，再监督训练轻量压缩器。 | 真实输出损失驱动的搜索监督已有先例；搜索变量是 token 子集，而非语义内容不同的图像对。 |
| [AVEX-Prune，2606.10533v1](https://arxiv.org/html/2606.10533v1)，§3.3–3.4 | 基于当前策略选出的集合，交换边界处的保留与未保留 token；冻结 captioner 的 CIDEr 奖励差监督策略，部署时移除交换及奖励计算。 | 当前策略相关的反事实反馈、训练阶段搜索与实际下游奖励已有先例；其干预是 token 集合交换，而非改变图像真实内容和对应正确答案。 |

以上边界比较是我们对所读算法的判断，不是各论文作者对本候选方法的评价。尤其不能将“使用当前模型”“使用反事实”“从实际回答错误学习”“训练阶段昂贵、部署阶段一次前向”分别作为独立的新颖性主张。

目前可以检验的较窄算法主张是：对当前压缩器主动搜索可验证的图像语义最小编辑对，要求完整教师在两侧都给出正确且应有的答案关系，并以压缩器的语义区分失败决定样本优先级；训练后再次按更新模型挖掘。这里的新颖性候选是搜索对象、压缩特有的成对验证条件及持续更新的数据选择规则的具体结合，仍须扩大检索和实验对照确认。

必要对照包括普通蒸馏、随机编辑、固定难例、持续挖掘，以及将相同挖掘数据交给普通训练。需同时控制更新次数、样本曝光和搜索成本，并检查真实未编辑文档及未见来源版式。只有动态挖掘在这些对照下产生可重复增益，才支持把训练闭环而非数据增量或损失更换作为贡献。
