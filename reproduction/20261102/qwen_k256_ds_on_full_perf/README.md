# EADP K256 DeepStack 开启：全量效果与性能基线

本目录是 Qwen3-VL-8B、DocVQA 验证集 5,349 题的本机实验。沿用已有 EADP K256、α=0.5、β=2、1024×1024、BF16 和 FlashAttention 2 设置，对实际选中的位置注入对应的三层 DeepStack 特征。该实现是在公开剪枝路径上修改的诊断配置，不是已确认的论文主表配置。

`benchmark.py` 保存每题答案、生成 token、实际选择位置、端到端耗时、首轮语言模型 CUDA 事件耗时，以及 PyTorch allocated/reserved 显存峰值；模型加载时间单独记录。端到端计时覆盖图片读取、预处理、视觉塔、选择、生成及解码，包含轻量观察钩子，不含加载和结果校验。显存含常驻模型，不等同显卡总占用。预热不计入正式样本；自然生成长度不同会影响总耗时。

运行先核验输入、权重身份、单设备环境、预热和前 16 题与此前真实结果的一致性，再逐题保存、检查选择，并记录与此前答案及 token 的一致性。只有全部完成、容器和根执行会话均成功退出后，才能用独立目录 `../qwen_k256_ds_on_full_analysis/` 中的程序汇总和评分。

旧的完整开关实验包含额外观测开销，不能用其墙钟时间作为本次开关速度对照；此前 16 题同口径配对测试见 `../qwen_k256_ds_performance/RESULT.md`。今后比较其他方法时应统一模型、数据、输出协议、token 预算、计时范围和 DeepStack 状态。
