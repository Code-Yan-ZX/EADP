# EADP K256 开启 DeepStack：DocVQA 全量效果和性能

2026-11-02，本机单张 NVIDIA A40，Qwen3-VL-8B，BF16、FlashAttention 2，EADP K256、α=0.5、β=2，固定图片尺寸 1024×1024，自然生成、最多 2048 个新 token。对作者公开剪枝路径进行修改，把同次视觉塔产生的三层 DeepStack 特征按实际保留的 256 个位置传入语言模型。该实验不是已确认的论文主表运行配置，也不将恢复已有模型结构称为新的剪枝方法。

## 效果

| 项目 | DocVQA ANLS | 说明 |
|---|---:|---|
| 论文 EADP | 62.8000 | 论文数值；完整运行配方未公开确认 |
| 本机旧全量：DeepStack 关闭 | 61.1660 | 已完成的同模型 K256 配对实验 |
| 本次全量：DeepStack 开启 | **67.9031** | 新运行 5,349 题，作者评分和独立评分逐题一致 |

本次开启结果比本机旧配对关闭结果高 **6.7371 个 ANLS 点**。本次与旧开启实验的 5,349 题回答、输出 token ID、实际选择位置均逐题一致；旧配对实验的说明见 `../../20261028/qwen/doc_full_k256_ds_pair/RESULT.md`。完整分母保留，4 题生成达到 2048 token 上限且没有 EOS；作者 Excel 读取有 6 条 NA 转换，独立评分按相同规则处理。

## 本次性能

| 指标 | 结果 |
|---|---:|
| 自然生成端到端时间，均值 | 0.7051 秒/题 |
| 端到端时间，中位数 / P95 | 0.5861 / 0.9582 秒/题 |
| 端到端最大时间 | 98.8291 秒/题 |
| 总测量时间 | 3771.445 秒（约 62.86 分钟） |
| 吞吐量 | 1.4183 题/秒 |
| 首轮语言模型 CUDA 事件，均值 | 80.665 毫秒 |
| PyTorch 已分配显存，整次推理峰值最大值 | 17104.961 MiB（约 16.70 GiB） |
| PyTorch 已预留显存，整次推理峰值最大值 | 17232.000 MiB（约 16.83 GiB） |
| 模型加载时间（单次） | 52.917 秒 |
| 生成长度，均值 / 中位数 | 7.362 / 5 token |

端到端时间由 CUDA 同步包围，覆盖图片读取、预处理、视觉塔、EADP 选择、语言模型生成和解码及轻量观察钩子，不含模型加载和后续验证/保存；总测量时间为各题耗时之和，不等于进程完整墙钟时间。首轮语言模型事件包括 DeepStack 选取/注入和首次 LLM forward，不包含视觉塔、选择器，也不是完整模型的首 token 时延。显存数字包含常驻模型，是 PyTorch allocated/reserved，不是设备上所有进程和分配器的显存总占用。

自然输出长度不同会影响耗时，少数长输出也保留在以上统计中。旧全量对照采集了额外大张量，且没有相同的逐题计时，因此不能用旧运行墙钟与本次数字计算开关的速度差。此前同口径 16 题、固定输出长度的开关对照另见 `../qwen_k256_ds_performance/RESULT.md`，其开销差很小且低于题间波动；它不是全量性能对照。将来比较其他方法，需固定相同模型、硬件、数据、token 预算、DeepStack 状态及计时范围，并报告输出长度。

原始逐题输出、耗时和显存：`observations.jsonl`；环境及加载时间：`runtime_*.json`；完整核验、性能分布及官方/独立评分：`../qwen_k256_ds_on_full_analysis/results/report.json` 和 `per_question.jsonl`。生成根会话和评分容器均已实际退出 0；原始文件哈希与退出记录保留在本目录。独立只读终审已重算全部逐题 ANLS、核验作者评分文件，并复算全部性能分布，结果一致。
