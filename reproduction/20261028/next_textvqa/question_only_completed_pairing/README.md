# Complete-only question-guidance pairing

Prepared CPU-only analysis; no automatic launch or watcher. The companion
generation continues under its existing frozen plan. This directory does not
modify that plan, either prediction set, the scoring artifacts or the ledger.

`pair_completed.py` compares the new full5000 question-only pruning-guidance
hypothesis with the accepted same-K64/.5/beta1/three-wait full-guidance control.
It only consumes each accepted independent per-question score, in integer
tenths. It never normalizes an answer, parses GT, invokes an evaluator, generates
an answer or imports torch/model modules.

Default invocation reads no run artifact and writes no output. Actual execution
requires the exact SHA256 of the new root-confirmed terminal proof as its sole
argument. Before opening or hashing either run's predictions, pointwise scores
or observation files, both sides must pass full5000 native/controller state,
successful author and independent verification, release/report/plan/allocation
SHA links, root-owned PTY actual exit0 and the original process identities'
actual exit. The old rootproof is already fixed. The new rootproof must identify
PTY60045, controller2861700/ticks1333486787 and native2861704/ticks1333486819;
both new identities also bind the boot ID. The two allocation filenames and
root/snapshot field names are explicitly fixed by side. Failed or incomplete
metadata reject pairing before any prefix access; there is no retry or polling.

After the gates, all5000 rows join by exact ordered question ID, full OCR prompt
SHA, image and unchanged full LLM input-ID SHA. Actual recorded packages,
backend flags, loaded model/dtypes/source paths, waits and generation arguments
must agree except for the isolated answer output path. The new executed entry
code must match its frozen one-insertion AST proof, and all actual question-only
guidance hashes must match the existing exact5000 references.

Reports preserve every raw answer and accepted score, with improved/declined/
unchanged counts and exact full-denominator delta. They also compare output IDs,
actual per-crop quota vectors, retained totals, final mask indices and retained
ordered prefixes. Discarded internal maxT suffixes are not treated as inputs.
Mask changes do not establish equality of unrecorded per-question pixel or
projected-feature arrays.

The only strata are fixed before results using
`guidance_question_boundary_exact_token_rows.jsonl`: original full guidance
length >77 (881 questions) versus <=77 (4119). They cover all5000 and reconstruct
the complete integer score sums and gains/losses. No score, output or new mask
selects samples. Stratum percentages are Decimal displays of accepted score
sums; they are not new metrics or re-evaluated scores.

Outputs are created once as `paired_rows.jsonl` and `comparison_report.json`;
they never overwrite old artifacts. All consumed inputs are hashed before and
after analysis. The question-only setting remains a public-comment-supported
input hypothesis, not confirmed paper argv, a confirmed repair or proof of
paper-level causation. Positive and negative results are retained alike.

Preparation tests use only synthetic observations/score values and mocked
terminal gates. They do not read the running prediction prefix or score it.
