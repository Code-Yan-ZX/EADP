It is a feature-space comparison, not a proposed accuracy gain, causal interpretation, timing result, general equivalence proof or claim of new method. ## Fixed rule

Accept exactly four finite floating arrays `z_s[H,W,D_s]` on an even 32×32 merged-token grid with H=W=32, original row-major spatial IDs 0..1023; the grid/order and provenance must be verified against the accepted input and archive at actual analysis. Any odd/non-32 shape, wrong token order, nonfinite element, inconsistent stream or missing identity is a hard failure, no fallback. Convert to float64; define per-image scale `a_s = sqrt(mean_i sum_d z_s(i,d)^2) + 1e-6`. The epsilon is fixed, including the all-zero scale case. Define `d_s(i,j)=||z_s(i)-z_s(j)||_2/a_s`.

Partition the 32×32 grid into disjoint contiguous 2×2 blocks, ordered by top-left row-major ID. In every block select exactly one ID `j*=argmin_j max_{i in block} max_{s=0..3} d_s(i,j)`; exact float64 ties use smallest original spatial ID, with no tolerance or posthoc parameter adjustment. Retain original ID and align all three DS streams and P3 positions, sorted in spatial order. This exact set construction selects 256 positions; it does not reconstruct removed decoder inputs or alter attention. The separately reported objective is each block's worst four-stream distance to its own representative and the maximum across all blocks. Per-block optimality is definitional and supplies no guarantee for original model output: removal changes sequence and softmax normalization, so no logit/answer bound is asserted.

Also compare each full selection against prior EADP K256 ordered/spatial IDs as set overlap and report EADP's count of blocks with zero/one/multiple retained IDs; do not claim block radius superiority over EADP on blocks where EADP has no representative. K256 spatial overlap is not answer quality.
