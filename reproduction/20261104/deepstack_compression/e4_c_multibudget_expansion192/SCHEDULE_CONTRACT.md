# Frozen pre-selection schedule and proposal scope

Selection follows `SELECTION_PLAN.md`. The following scheduling rule is fixed before opening the expansion's chosen identities. The scheduling-only domain is UTF-8 `EADP-E4C-192-SCHEDULE-v1`. Hash keys are `domain|image|phase|replicate|task|group_id|qid` for image order and `domain|arm|phase|replicate|task|group_id|qid|budget|protocol` for arm order; SHA-256 lowercase hex then the corresponding literal tuple breaks ties. Emit all warmups first with one replicate, followed by measured replicates 0 through 4. For each replicate sort images by image key, then sort their eight budget/protocol combinations by arm key. K is one of 128,256,512,1024; protocol is natural or fixed32. Every warmup runs all eight arms once; each measured image runs all eight arms five times.

The 192 selected task/group identities are chosen without target predictions or labels; all 62 prior pilot task/groups are excluded. The prior 30 warmups are reused only for warmup. Identity matching is against both frozen E1 input preparation and DEV panel, along with the already-frozen 384-question anchor list. Processor metadata in the anchor list is preserved as a prior reference but is not independently reconstructed here. The dataset fields contain no answers. Full source/processor/visual/selection/output identity, fixed32 reference generation, observed monitoring, complete formal and independent acceptance, and a separately frozen executable analysis are future prerequisites.

This is a posthoc exploratory proposal, neither execution authorization nor an asserted runtime. 7,920 jobs consist of 240 warmups and 7,680 measurements; 888 fresh 32-token references cover 222 distinct identities × four budgets. Keep all outputs/errors; no partial scoring or exclusion by result. GPU work remains locked; the three-day absolute end is taken from `initial_plan.json`. A 32-image pilot's actual wall time is only a rough scaling anchor and cannot predict or authorize the longer measurement, reference generation, preflights, load, interference, or verification.
