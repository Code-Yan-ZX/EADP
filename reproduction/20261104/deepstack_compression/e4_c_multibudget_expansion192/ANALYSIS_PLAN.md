Fix this analysis after seeing the 32-image pilot and existing DEV results but before any expansion timing or generated outputs are read. For every task, protocol and budget, take the median of five TTFT values within each image, then report the median, minimum and maximum across the 64 image medians. TTFT starts immediately before reading the image and ends after the first selected token and CUDA synchronization. Repeat for synchronized generate completion, which excludes token transfer, fsync and answer decoding and is not complete user-facing end-to-end latency. Natural-greedy completion varies with actual output length; include per-job token count, EOS and truncation. Fixed32 means exactly 32 generated tokens and 31 subsequent decode forwards. Report the two protocols separately.

Within each task and protocol, calculate for each image the difference and ratio of each K-specific five-run median to that same image's K256 five-run median. Fixed output generation is not a quality measurement; same K across methods does not prove equal compute.
