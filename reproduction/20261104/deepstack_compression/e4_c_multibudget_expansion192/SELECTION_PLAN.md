# Proposed E4-C 192-image four-budget expansion

This is an exploratory expansion after the three-anchor and 32-image pilot results and after earlier DEV quality analyses. A fresh, non-overlapping measurement cohort reduces reuse of pilot examples but does not make this a preregistered confirmatory study: the original DEV labels and earlier results have already been examined. Do not use CONFIRM or FINAL inputs.

Use the 384 accepted DEV question/image identities from `e6/pixelprune_t045_dev384/plan001.json`; verify their identity against the accepted E1 input manifest without loading labels. Exclude all 62 task/group identities present in `e4_c_multibudget_expansion/pilot_plan001.json` (the 32 measurement and 30 warmup groups). For each task independently, rank all remaining unique image groups by the lowercase SHA-256 hexadecimal digest of UTF-8 `EADP-E4C-192-v1|{task}|{group_id}|{qid}`; sort ties by group ID then question ID and select the first 64. Reject any duplicate task/group or question identity and any task with fewer than 64 eligible groups. This rule was set before inspecting this expansion's sample identities, model outputs or any additional labels. The prior pilot's same 30 disjoint warmup inputs may be reused for warmup only; they never enter measurement statistics.

Measure every selected image at K128/K256/K512/K1024 under natural greedy and exactly 32 generated tokens (31 later decode forwards), five repetitions per protocol/budget per image: 7,680 measured jobs. Warmup is one run for each of the 30 warmup images, four budgets and two protocols: 240 jobs. Fix deterministic interleaving before running, perform actual source/processor/selection/output identity checks and maintain one GPU workload at a time. All 7,920 jobs, 888 fixed32 references (222 input identities times four budgets), identities, errors and background windows must be kept; never calculate partial-panel statistics or cherry-pick samples.

Freeze a complete executable analysis plan and test it independently before target measurements; use each image's five-run median, pair all four budgets by image group within task/protocol and apply a fixed-seed paired image-group bootstrap. Separately report TTFT and synchronized generate completion, explicitly excluding post-generation token copy/fsync and text decoding from completion; natural output length varies and fixed32 is not natural quality. Do not silently reuse the prior pilot measurements as new repetitions. Record observed monitoring windows and all unobserved residual uncertainty. Required source gates, fresh fixed32 reference generations, supervised deadlines, no-GPU preflight, model run and formal and independent checks remain to be implemented; this proposal alone authorizes neither GPU execution nor any actual sampling output.
