# E1 DEV 原始问题类型与回答变化（探索性）

使用 E1 已完成且独立验收的 384 道 DEV 题及对应评分；每任务 128 题、128 个互不相同图像组。DocVQA 的 `question_types` 为原始多标签，标签可重叠；AI2D 使用原始 `category`，TextVQA 的当前 TSV 没有对应类型字段。只在字节层筛选 DEV qid 后解析选中行；TSV 整文件字节哈希用于校验文件身份，不解析其他行答案。

下表为 P3 下开启 DS 相比关闭 DS 的同题分数变化，单位为百分点；“回答变更”比较原始输出字符串。三个任务分别 128 题。

| DocVQA | +7.17 | 19 / 9 / 100 | 42 |
| TextVQA | -0.94 | 3 / 5 / 120 | 15 |
