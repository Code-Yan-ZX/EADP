# 192-image timing worker candidate, CPU-only and locked

This directory contains a real-model timing candidate, not an authorization to load a model, run a container, read target outputs or use a GPU. It references the independently reviewed posthoc DEV proposal with 192 new images, 30 old warmup images, and 7,920 fixed jobs. It reuses the already reviewed 32-image `runner.py` for actual source image read, synchronized first-token and synchronized generation-completion boundaries; generated token output is fsynced before further checks. Natural outputs must equal accepted same-image/same-budget E4; fixed32 outputs must equal newly generated 888 same-input/same-budget references, with recipe/EOS and 32 tokens. All job starts, raw generation, results and failures remain recorded. No partial summary or automatic resume is authorized.

`gate.py` currently rejects both CPU-container preflight and GPU requests unconditionally. `worker.py` checks its SHA before loading it, and the existing GPU candidate calls it before loading E4 records, 888 outputs, torch, or model. `fixed_reference_gate.py` is prepared for the future formal and independently reviewed 888-reference evidence and refuses to open its record file before both proofs and real supervisor exits. These code paths and their exact source hashes must be independently reviewed again whenever altered. The candidate completion deliberately lacks final source/weight rechecks and is unreachable while the lock is active.

A future revision must implement and freeze a complete executable plan, source/weight and container proof, 222-input CPU processor preflight, real 888-reference formal/independent result and source snapshot gates, independent admission reviews, exclusively scheduled GPU, same-namespace observer/manual health, budget/deadline and progress-stall/TERM/KILL/container-inspect chains, post-run weight/source and file checks, complete frozen formal and independent 7,920-job acceptance, then pre-reviewed statistical and background analysis. A clear bounded runtime and acceptance reserve must fit the user's original three-day deadline. Missing or uninspectable evidence must not be converted into success. Source/weight stat checks alone cannot exclude transient replacement.

The 192-image expansion is exploratory and posthoc after earlier DEV/pilot observations. It is not confirmatory. Fixed32 has 31 decode forwards after prefill; generation completion excludes token copy/fsync and answer text decoding. Unknown unlogged activities, observer second fsync and manual health log fsync remain explicitly unknown. The 888 fixed32 reference generation and worker CPU preflight are not currently completed or authorized by this directory.
