# M3 前期相关工作核查（2026-11-05）

本页只记录公开论文的方法边界，不引用其论文跑分作为本项目结果，也没有声称已在本机复现。M3 目前只有预注册的有界诊断和 CPU 合同，尚无可部署候选。

- [CoRePrune: From Token Importance to Conditional Removability](https://arxiv.org/abs/2609.26484) 在视觉编码阶段逐步更新扰动估计，并在视觉—文本交互后根据当前删除集合重新评估候选的救回收益；其方法是训练自由的两阶段选择。因而“考虑选中/删除集合的条件收益”本身不能作为本项目新意。当前 M3 的答案条件离线搜索只是机制诊断，若后续 student 能工作，仍需说明其可用输入、监督及部署成本与该路线的可验证区别。
- [MVP: Multi-View-Guided Token Pruning for Vision-Language Models](https://aclanthology.org/2026.emnlp-main.2066/) 已用多个互补剪枝视角提供监督，并训练轻量模块预测 token 重要性。因此“结合多视角监督训练轻量 token scorer”也不能单独作为新意。当前四路视觉流与参考答案梯度只是待验证的具体监督假设，是否带来可部署且不同的收益尚未知。
- [SieveServe: Adaptive Visual Token Pruning for Reliable and Efficient Multimodal LLM Inference](https://aclanthology.org/2026.emnlp-main.648/) 已提出依据问题复杂度与图像信息密度进行自适应决策的服务兼容方案。因此，即便后续测出不同任务需要不同预算，简单的查询/密度路由也不能预先宣称为创新；必须比较同成本固定预算和实际系统代价。

这些资料仅用于限制可提出的主张和后续基线选择；不能据此填充缺失实验、推断本机性能、改变已经冻结的 E2/E3 或 oracle 规则，或声称这些相关工作覆盖了所有已有方法。若相关候选最终值得继续，还需检查原文具体监督、代码和对照协议。
