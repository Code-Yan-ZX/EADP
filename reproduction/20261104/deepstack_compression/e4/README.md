# C-SKIP primitive: CPU preparation only

`skip_deepstack.py` provides a scoped instance patch for the three Qwen3-VL DeepStack-specific merger forwards. It leaves the original visual `forward`, all visual transformer blocks, patch embedding and main visual merger in place; the stock vision return retains three DeepStack slots, each `None`. It rejects invalid or duplicate merger/index configurations, a merger aliased to any visual backbone or main-merger module, and nested skips on the same merger; it restores all patched forwards on exit, including exceptional and partial-entry failure paths. This is a process-local, non-thread-safe intervention: do not share a model across concurrent calls while it is active.

```python
from skip_deepstack import SkipDeepStackMergers, require_skip_visual_result

# Call only inside an E4-specific DS-off forward path.
with SkipDeepStackMergers(visual, audit_calls=True) as audit:
    result = visual(pixel_values, grid_thw=grid_thw)
    main_features = require_skip_visual_result(result)
    assert audit.skipped_calls == [1, 1, 1]
```

For a timed run, use `audit_calls=False` and perform counters, hashes and detailed observers in a separate diagnostic execution; do not call the existing E0 adapter unchanged, because it indexes all three DS tensors.

`off_adapter.py` supplies an E4-only diagnostic DS-off prefill hook: it observes the actual author greedy order, validates that the selected positions reconstruct the actual pruned primary features, retains all text, gathers full-image P3 positions, adjusts the decode delta and verifies that the prefill actually receives no DS injection. It records calls to each backbone block, the main merger and each DS merger. `identity_records.py` records and compares processor/main-visual/pruned-visual hashes, actual selection, position/cache setup, first-step logits and natural token/text output for C-DROP and C-SKIP; its current comparison requires bitwise equal logits and output identity. A failed exact comparison must remain a failed/unresolved gate; a different numerical tolerance would require a separately frozen protocol.

`identity_worker.py` is a prepared but **not yet executed** natural-generation diagnostic. It refuses to proceed unless E1 full DEV has its independent acceptance proof, matching source files and a clean real process/container exit. It verifies the frozen E1 input identities, excludes all pre-existing E0 anchor groups and selects 16 deterministic DEV DocVQA groups. It checks the expected K256 recipe, actual model weight hashes, versions and GPU exclusivity before generating both modes. It writes each raw identity record and a comparison to a new directory; a worker completion file alone does not prove container/supervisor exit. It has no launcher here: before a real run, independently review the integration and use a bounded launcher with real exit, failure and source-hash evidence. No E4 GPU execution is authorized or started by importing/testing these files.

`cpu_check_023/verification.json` records source SHA256 values before and after an isolated `CUDA_VISIBLE_DEVICES=''` author-environment subprocess, its zero return code, and the hashes of its logs. Twenty-seven tests pass: the three original DS forwards are skipped, backbone and main-merger execution continue, original methods and hooks are restored after normal/error exit and a partial patch failure, aliases/invalid indexes are rejected, the fixed author vision source has the expected structure, and synthetic C-DROP/C-SKIP and budget records and controls reject corruption, including forward in-place mutation, 32 decode/KV steps, nonfinite logits and incomplete panel admission. ## E4-A budget preparation

`budget_adapter.py` validates author-selected 128/256/512-token budgets by observing the actual greedy call and reconstructing its spatially sorted features. K1024 must take the author's keep-all bypass and make no greedy call. For each budget it gathers the original three-axis position IDs and adjusts the decode delta, applies the same spatial indices to all three computed DeepStack streams, and verifies the actual injected mask and streams for DS-on or their absence for DS-off. `budget_runner.py` is an instrumented single-arm core that records natural outputs (including empty strings and truncation), processor, selection, primary and DS features, positions and call counters. It only accepts DEV-labeled inputs and has no CLI or autonomous execution path.

The core is **not yet an admitted panel runner**. Before scheduling GPU work, add and independently review a launcher and verifier that bind accepted full E1, the frozen 384-input manifest and actual image/message hashes, model/recipe/versions, deterministic generation, each budget and arm, real process/container exits and a hard deadline. Run a bounded real-model smoke and verify actual P3 prefill/decode/cache plus on/off stream alignment before authorizing the full panel. Observer overhead makes the core unsuitable for E4 performance timing.

K256 E1 reuse is forbidden until an independent verifier compares the accepted E1 record and E4 result on identical inputs, model/recipe/backend and generation protocol, processor, primary/DS features, actual greedy and spatial IDs, P3 positions and delta, injection, and the complete natural output including EOS/truncation. `budget_reuse.py` only names required evidence categories: caller-supplied booleans are not proof and must never be used alone to authorize reuse. No E1 prediction has been read by this preparation and no actual model identity or E4-A result is asserted.
