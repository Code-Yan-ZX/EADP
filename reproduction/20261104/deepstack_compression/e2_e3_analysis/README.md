`score_core.py` 和 `score_panel.py` 是后续 DEV 评分入口的准备代码：在解析任何全面板预测或读取答案前，入口要求正式与独立验收、监督器和实际容器干净退出、完整文件与锚点数组哈希，以及 E1 输入证明。`monitor_scorecore007` 的 11 项合成测试（包括作者与独立计分对照、完整合成验收以及记录/数组/源码篡改和验收器未退出反例）在作者环境退出 0；首次基础环境缺少 `xlsxwriter`、另一次导入路径错误的失败均原样保留。该入口仍须独立审查，并等待完整的 3840 臂真实结果及独立验收；尚未用它读取真实标签或计分。
