# K1024 stock-native identity diagnostic

This independent directory prepares the missing real-model endpoint check. It picks the first frozen smoke group in each of DocVQA, TextVQA and AI2D, without changing prompts or inputs. On one model object it compares the author's `Qwen3VLChatFixedRes.generate_inner_transformers_fixed` stock native path against the author's keep-all K1024 plus P3 and three DeepStack streams. The native path does not install the E4 budget adapter. Natural generated IDs are cut after the exact native prompt prefix; the budget path returns its generated IDs directly.

Each of the three anchors is run through both paths naturally and with a fixed 33-token prefix, giving 12 generations and six pairs. The diagnostic stores actual processor, full main and three DS features, prefill and injected DS arrays, first logits, natural output tokens, positions and all layer cache lengths. It hashes actual per-layer KV tensors at prefill for natural runs and at prefill plus each of the 32 decode steps for forced runs. Its verifier requires strict tensor, logits, decoded text, token, position and KV-hash equality and checks supervised process/container exit. Such diagnostic hashes and copies add overhead and cannot be used as model latency.

`cpu_check_002/verification.json` documents five synthetic CPU tests and source hashes. This is not a real-model identity result. `native_approval.json` is absent: the bounded launcher and worker cannot run until exact source/CPU evidence is independently reviewed and explicitly bound. E1 full, E4 smoke acceptance and independent E4 smoke review must also have clean supervised exits. No GT or scores are used. A task-specific prompt or native input failure remains a failure artifact and must not be silently repaired or skipped.
