# Post hoc multi-stream signal versus E4 budget gain

This is an exploratory diagnostic, proposed after seeing existing DEV results and the 32-image selector pilot. It does not establish novelty, causality, a deployable router, or confirmatory efficacy. This plan is frozen before inspecting any individual feature or score for this diagnostic. No labels or answer source will be opened or used for training; already scored mixed DEV files contain model predictions and will be opened only after independent prelaunch review, with the value use restricted to the three fixed scores and identity fields.

## Cohort and evidence

Use all 32 pilot identities in the existing frozen `e5/selector_real32/sample_manifest_001.json` in manifest order: 11 DocVQA, 11 TextVQA, 10 AI2D; one unique image group per question within each task. Use their 32 `capture.pt` archives whose per-file hashes and E1/E4 input identities were verified by formal and independent selector review; capture field `actual.visual[0]` is the main stream and the three tensors in `actual.visual[1]` are the three DeepStack streams. Match each task, qid and group_id exactly to the independently scored E4 full DEV records, and use the selector review's same-image, message and E4 identity evidence. For E4 read only `K128-D1`, `K256-D1`, `K512-D1` official and independent scores; reject any nonfinite/out-of-range score or official-independent disagreement greater than 1e-12. All image archives, selected identities and scores must exist exactly once; any missing, corrupt, failed or mismatched input invalidates the complete planned diagnostic and is reported as a failure with no selective cohort reduction. SHA checks bind the full predictions-containing file and may open it for bytes; its JSON payload is parsed only after dual prelaunch proof, and answer strings are neither used nor reported.

The existing selector pilot independently passed 32 images and 96 author-budget cases; the known fused/graph K512 ordered disagreement is unrelated to the author feature archive and is retained in provenance rather than excluded. Existing E4 formal+independent inference and formal+independent score proof, source SHA and supervised exit chains must be checked, as must selector formal+independent proof, per-archive SHA and all task/qid/group/image/message bindings. No full E4 high-dimensional tensor reconstruction is claimed: the locally archived selector capture is directly compared with its independently accepted hash and prior E4 metadata.

## Features fixed before looking at values

For each image, obtain exactly 1,024 aligned tokens from each of the four streams; accept only an optional singleton batch dimension and matching token counts. Compute norms in CPU float64; reject NaN/Inf. For each stream calculate the population coefficient of variation of its 1,024 token L2 norms (`population std / mean`); if the mean is zero, report the feature as undefined. This gives four simple stream features.

Compute average-tie ranks of each stream's token norms, scaled to [0,1] by `(rank-1)/1023`. Compute three main-vs-DeepStack Spearman correlations as Pearson correlations between the corresponding ranks; if either rank vector is constant, the feature is undefined. The eighth feature is mean over 1,024 positions of the population variance across the four percentile ranks, measuring cross-stream rank disagreement. No feature uses ground-truth labels or answer-derived targets; ties use average rank and token alignment must be established by the prior capture identity. These exact eight features, including undefined values, are retained in the output.

## Outcome and comparison

For each image define the sole primary outcome as official-score `K512-D1 - K128-D1` in native score units, with K256 recorded for the fixed trajectory but not used to tune a decision. For each of the eight prespecified features and each task separately, report task/qid/group count, the number of feature-defined and outcome-defined samples, and Spearman correlation with the outcome, using average-tie ranks and the complete eligible manifest. If a feature or outcome is constant or fewer than three pairs are defined, report the correlation as undefined and its reason; do not substitute zero or drop an image without recording it. Report every feature and every task, including non-associations. No threshold optimization, routing, training, held-out claims, feature picking, multiple-comparison significance claim, or combined-task correlation will be made; at n=10/11 per task even large apparent effects can be unstable. Compare the three cross-stream correlations and disagreement feature descriptively with all four single-stream CV features; do not claim superiority based on the largest coefficient.

No GPU is authorized. Archive only features, fixed score deltas and identity/provenance, not answer text or new labels. Before actual extraction, freeze executable source and CPU-only synthetic tests and obtain an independent source/plan review. After completion, independent recomputation from all source captures and scores, source/exit/hash verification and explicit mixed-prediction-access disclosure are required before reporting values. Results remain exploratory and must not consume or select CONFIRM/FINAL.
