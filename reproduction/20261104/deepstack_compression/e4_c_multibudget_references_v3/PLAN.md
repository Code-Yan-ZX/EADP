# Fixed32 参考生成计划（GPU 尚锁定）

目标是按已冻结 pilot 的 62 条 DEV 输入 × K128/256/512/1024，使用 fresh E4 预算诊断路径逐臂真实生成 248 条 fixed32 参考：原作者自然 greedy 配方，min_new_tokens=max_new_tokens=32，保留原 EOS；每臂先持久化实际序列，再做摘要和验收。不读 GT、不评分、不报告速度，不以未完成的输出选择样本或方法。

每臂与已验收 E4 同题同预算的 processor、原视觉主干和三路 DS、顺序/选点、P3、mask、完整 prefill 指纹及首步 cache 记录逐项绑定；保存 32 输出、prefill 与31次 decode 的每层 KV 长度/位置，以及首次 prefill 的36层 KV 指纹。只做张量摘要与 KV 指纹，不声称把所有 KV 内容存档。12对 fresh 与轻量的完整高数组/每步 KV 指纹身份试验独立进行；该身份试验的正式验收和独立终审、248参考自身的正式验收及独立终审通过后，才能为完整时延 pilot 准入。

248 次固定32的新增 GPU 工时缺少直接观测：先以 5400 秒内层硬限、5520 秒监督硬限、1200 秒无完成臂停滞和 90 秒清理宽限做保守运行上限，并保留至少 3600 秒期限内验收余量；实测可能更快或超限，超限完整留证、不静默重跑。权重哈希和62题 CPU processor 前检另计；不将上限当运行时间估计。该预算不能代替 GPU 独占、容器停止/退出、来源冻结与独立预审。实时调度由主控决定。
