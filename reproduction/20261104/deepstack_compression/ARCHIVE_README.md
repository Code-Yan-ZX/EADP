# Experiment archive

This archive records the 2026-11-04 through 2026-11-06 DeepStack compression research. See `docs/project_handoff.md` for the research history, the current status and the limitations of each conclusion. Individual `RESULT.md` files report their own methods, inputs and verification; files for incomplete experiments are retained as work in progress and are not evidence of completed runs.

The Git archive includes experiment reports, structured results and predictions, analysis and execution scripts, plans, and available independent verification records. It excludes downloaded training datasets and shards, model weights and binary tensor caches, dependency installation caches and environments, other ignored binaries, and non-text runtime artifacts. Some manifests and historical records therefore point to local artifacts not included in Git; a fresh checkout alone does not reproduce every run or independently verify every referenced hash. Recover the referenced inputs and environment separately before attempting reproduction. Existing source and result files are preserved as recorded; paths and process identifiers are historical rather than portable instructions.

The ongoing R-res/EADP full paired timing experiment had not started when this archive was created. Three-image identity checks and CPU tests are not full-run timing results.
