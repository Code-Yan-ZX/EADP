# 无标签预算规则：DEV 离线筛查

先从 384 个 DEV 图像和用户消息提取预先定义的三个特征，再读取已验收的 E4 每题 K128、K256、K512 / DS-on 分数。每个任务各 128 图：按特征从大到小给 42 图分配 K512，其余 86 图分配 K128，平均 K254；同分按固定 SHA256 规则处理。三个随机种子采用完全相同的 42/86 数量。固定 K256 是对照。没有生成新预测或读取新标签。

全部预定规则都报告在 `analysis.json` 和 `assignments.jsonl`；`e1_independent_review/e4_adaptive_features_review003.json` 独立重算了全部图像特征、2,304 个分配及相应得分。规则及阈值数在本次提取前固定，但设计发生在已经查看 DEV 汇总和答案条件 oracle 之后，是后验探索。三条简单规则都没有在此批样本上优于固定 K256；这不能证明其他特征或控制器无效，也不能从小差值推非劣或显著性。

排名需要预先看到每个任务的一整批 128 图及任务身份，尚不是可在线执行的控制器。平均 K254 与 K256 也不表示同等实际计算、延迟或显存，特征提取和控制成本未测；真实部署需要独立校准、强动态预算基线及完整实测。
