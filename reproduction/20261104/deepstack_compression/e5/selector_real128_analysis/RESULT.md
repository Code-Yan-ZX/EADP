# 128 图实际选择器输入：身份和局部计时

固定 DEV 清单包含此前观察的 32 图和随后扩展的 96 图；扩样决定发生在查看前 32 图结果后，因此合并结果不是 128 张全新独立验证。每图分别比较 K128、K256、K512；融合 kernel 和它的 Graph 重放共用同一归约核心。

| K | 完整有序选点与作者一致 | 最终集合与作者一致 | 原作者 / fused / Graph 局部时间中位数 |
|---:|---:|---:|---:|
| 128 | 128/128 | 128/128 | 18.291 / 13.027 / 1.703 ms |
| 256 | 128/128 | 128/128 | 36.313 / 25.893 / 3.357 ms |
| 512 | 127/128 | 128/128 | 72.288 / 51.510 / 6.877 ms，127 对 |

时间为每图五次 CUDA event 计时先取中位、再跨图取中位。K512 原作者全部 128 图的中位数为 72.291 ms；表内是 127 个有序身份通过的配对图。唯一失败的旧 TextVQA 35191 在第 333 个选点起发生两处顺序互换，最终集合相同；按预设身份门其候选各五次计时未执行。故 K512 计时有选择偏差，最终集合相同是事后观察，不能替代原先严格有序身份门。

Graph 捕获初始化约 215–255 ms、每个 K 对应 Graph 的 PyTorch allocated 约增加 4.2 MB，单列且不计入重放时间；不能把它写成设备峰值。两批实验均受可能变化的后台活动影响，扩样计时期间有一次未留精确时间窗的轻量代码编辑，影响无法逐测次定位，所有样本保留。这些是 warm-cache 组件测量，不是完整 selector 或首 token 时间，也不能证明普遍等价或部署收益。

身份合并的正式记录为 `combined001.json`，独立复算为 `../../e1_independent_review/selector_real128_combined_review.json`；计时记录为 `timing001.json`，独立复算为 `../../e1_independent_review/selector_real128_timing_review.json`。独立复算仅能检查已归档的实际索引、计时和身份记录；原 GPU 每轮浮点分数未归档。
