# PixelPrune 阈值 0.2 与 0.45：DEV 事后配对

两个面板使用相同的 384 个 DEV 题目与图像，每任务 128 题、128 个图像组。下表的分数为各任务作者规则得分百分数；差值为 0.2 减 0.45，单位为百分点。区间为同图配对、图像组重采样 10,000 次的 95% 百分位区间，seed 为 20261104；未做多重比较校正。改善、下降和不变计数均保留全部 128 题。

| --- | ---: | ---: | ---: | ---: | ---: |

| AI2D | 81.25 | 82.03 | −0.78 [−3.91, 2.34] | 2 / 3 / 123 | 385.5 / 347.5 |

阈值 0.2 的完整评分还与 PixelPrune 阈值 0、EADP K256 和 EADP K1024 配对；各任务分数、区间、K 范围和终止统计见 [0.2 DEV 结果](../pixelprune_t020_dev384_analysis/score001/RESULT.md)。0.2 的 384 次生成均以 EOS 结束，无截断或空答案。

阈值选择和比较对象均发生在此前 DEV 结果之后，属于探索性分析；两种阈值的动态 K 和计算量不同，不能从质量差值推断等算力优势或端到端时延。未使用 CONFIRM/FINAL 作此比较。0.2 的完整面板生成、无 GT 验收、评分和逐题独立复算均已完成；比较分析只读取既有分数文件，并未另开 GT，但分数文件包含预测文本。

比较计划在读取完整 0.2 评分前冻结。首版脚本在已读取该评分后，因引用 0.45 独立评分复核的错误监督路径而失败；v2 修复路径后运行，原脚本和失败监督均保留。固定种子下的图组 ID 排序在分数已可见后由脚本确定，计划未事先指定排序；更换排序会改变有限次重采样的具体区间。独立复核按 v2 的排序重算全部配对及区间，详见 [复核证明](../../e1_independent_review/pixel_t020_t045_comparison_review.json)；成功监督为 `monitor_pixel_t020_t045_comparison003`。
