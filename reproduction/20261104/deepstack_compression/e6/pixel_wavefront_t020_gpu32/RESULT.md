# PixelPrune 阈值0.2波前选择器：32图 GPU 组件诊断

在此前已经检查的32张DEV图像上，对同一阈值0.2的作者 anchored-max 选择器与波前并行实现分别运行一次同步主机wall测时；每图交替执行顺序，另以相同3×3输入预热。实验不含图像处理、输入传输或模型前向。32/32张图上，两个GPU实现的完整有序索引与独立重算的CPU参考均一致；结果由 `e1_independent_review/pixel_wavefront_t020_gpu32_result_review.json` 独立复核。

| 组件 | 每图单次耗时中位数 | 全部图范围 |
| --- | ---: | ---: |
| 作者 anchored | 183.37 ms | 178.29–232.97 ms |
| 波前并行 | 28.32 ms | 28.13–30.64 ms |

该32图是看过已有DEV与组件结果后复用的样本，每图每臂只有一次测量；前后进程快照无法确定计时窗内背景影响，GPU中间输入tensor未完整归档。结果是对固定输入组件的工程诊断，不是新剪枝算法、全模型等价或端到端延迟结论。独立结果审阅者没有编写候选，但参与过其继承的早期四图worker；完整限制见审阅证明。完整模型身份和自然首token仍须另外验证。
