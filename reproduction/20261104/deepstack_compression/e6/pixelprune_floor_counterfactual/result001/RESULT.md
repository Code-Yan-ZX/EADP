# 低 K 回退：DEV 离线反事实

先前发现 PixelPrune 阈值 0.45 的部分文档图实际 K 很低、同题分数也低。本分析在看过这些 DEV 结果后固定三条规则：如果该图实际 K≤128、≤256 或 ≤512，就引用同题已运行的阈值 0 输出；否则引用阈值 0.45 输出。三条规则均报告，每任务 128 题，未新生成或重新读取标签。

| 任务 | 对照：EADP K256 | 回退 ≤128 | 回退 ≤256 | 回退 ≤512 |
|---|---:|---:|---:|---:|
| DocVQA 得分 | 67.85 | 88.65 | 88.95 | 90.54 |
| TextVQA 得分 | 80.78 | 71.09 | 74.61 | 81.41 |
| AI2D 得分 | 82.03 | 82.03 | 82.03 | 82.03 |
| DocVQA 回退数 / 平均 K | — | 16 / 462.4 | 35 / 514.5 | 97 / 618.9 |
| TextVQA 回退数 / 平均 K | — | 11 / 401.4 | 40 / 528.4 | 110 / 747.9 |
| AI2D 回退数 / 平均 K | — | 0 / 358.1 | 27 / 377.8 | 116 / 483.9 |

≤512 相对 EADP K256 的同题差为 Doc +22.69 [+15.16, +30.23]、Text +0.63 [−3.52, +4.69]、AI 0 [−3.91, +3.91] 百分点；均为 10,000 次图组配对 bootstrap、未多重校正，Text 和 AI 的区间不足以支持预设 0.5 分非劣。其余阈值及全部对照、K 范围和 P95 见 `analysis.json`；全部 1,152 条路由及 27 个区间已由 `../../../e1_independent_review/pixel_floor_counterfactual_review.json` 独立复核。

这只是把两次先前独立运行的输出按观察到的 K 拼接，**尚未运行真正的条件选择器**。它假设条件实现能重现对应已存输出；实际方法要先运行阈值 0.45 selector，回退时再运行阈值 0 selector，额外计算、延迟和内存未测。K 也不是等算力：≤512 规则在 TextVQA 上 110/128 次回退，平均 K 接近阈值 0 面板。阈值是在同一 DEV 中看过结果后选择的；这些区间不是确认或泛化结论，未证明此方案成功。
