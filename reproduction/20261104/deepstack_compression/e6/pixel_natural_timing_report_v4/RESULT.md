首 token 区间从图像读取与预处理前开始，至已选 token 追加后的同步结束，包含选择器、实际视觉路径和语言模型预填充；模型加载和预热另列。Pixel 在视觉 blocks 前按输入裁剪，EADP 保留完整视觉路径后选择；K 是保留数量，不代表计算量。
