# PixelPrune τ=.2：192 图暖态单 token 实现对照

这项后验 DEV 实验在一块 NVIDIA A40 上比较作者选择器与波前实现。192 张图来自既有计时 cohort，每任务 64 张；四个 48 图块按 AB/BA/BA/AB 顺序由 8 个独立模型进程各处理一次，每进程另有 1 次热身，热身不计入 384 次测量。模型加载排除在计时外，每次请求使用新 KV；观察钩子和 cache-position 同步开销包含在两臂内。计时从读取图像前到首 token 选定，`max_new_tokens=1`，不能直接等同于历史自然生成的完整延迟或线上稳态性能。

| 任务 | 配对图数 | 作者 TTFT 中位数 (ms) | 波前 TTFT 中位数 (ms) | 配对差值中位数 (ms)，95% 图组 bootstrap CI | 配对比值中位数，95% CI |
|---|---:|---:|---:|---:|---:|
| DocVQA | 64 | 488.65 | 327.86 | -154.78 [-160.80, -151.31] | 0.6701 [0.6652, 0.6779] |
| TextVQA | 64 | 456.21 | 301.26 | -154.54 [-159.03, -152.39] | 0.6603 [0.6452, 0.6716] |
| AI2D | 64 | 420.80 | 267.12 | -153.68 [-156.07, -151.31] | 0.6371 [0.6287, 0.6435] |

差值定义为波前减作者，比值为波前除以作者；配对差中位数并非两个边际中位数之差。每任务以图组为单位重采样 10,000 次，PCG64 seed 20261105，区间未经多重比较校正。192 对全部纳入；完整有序选点、首 token、EOS ID 和首 token 是否 EOS 的臂间不一致均为 0/192。这些在线和归档记录只支持本次单 token 对照，不代表所有模型、输入或完整 KV 数值一致。

观察器 query/首次 fsync 窗与 TextVQA 的 2/384 次测量窗口重叠，其他测量未见已记录的观察器窗口重叠；两套监督健康检查窗口均未与测量窗口重叠。未记录人工健康检查窗口，因此其覆盖为 unknown；观察器第二次 fsync 和未采样时段的背景活动也无法量化。所有样本保留，不按干扰窗口筛选。已记录既有 DEV 混合预测用于身份绑定、未读取 GT 或进行评分；本样本与先前工作重叠且是在观察三锚结果后选择，不是独立确认性实验。
