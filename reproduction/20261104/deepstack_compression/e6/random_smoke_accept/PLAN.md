# Random K256 小样正式验收草案

本目录当前只有 CPU 合同和合成测试；没有真实执行/验收 proof，不授权 GPU。待真实无 GPU 前检及其独立终审完成后，在任何 GPU 小样生成前冻结验收入口、此合同、测试和运行计划 SHA。只有真实容器 stopped/PID0/exit0、GPU计算进程清理、外层监督 completed/0/组空、18臂及所有完整暴露 journal 齐全后，才能读取完整结果进行正式验收；验收不访问标签也不评分。后续须由另一审核者另行重算并核实其受监督退出。

对固定3个任务×3种子×自然/forced33的每条臂，独立加载同题正式 E1 身份、冻结选择manifest和归档数组，核本目录 `contract.py` 的随机索引、原图processor/视觉/三DS、P3位置、同分支实际注入、全量预填特征、首logits有限性、自然EOS/截断或33固定输出、真实36层逐步缓存长度及位置；forced33还检查实际33×36 KV元数据与指纹。重新解码 token，逐臂比对即时 fsync 的生成暴露与结果；任何丢失、重复、失败不得删除或复用为通过。对高维数组逐字节独立重算哈希和采样索引，不把摘要当作张量本身。

容器镜像、实际命令/设备/挂载、启动与真实停止、代码计划及监督身份必须从外部复核；还须核 `model_ready.json` 的传入模型构造器的 recipe、实际依赖版本与四片运行前 stat（逐臂实际生成参数另核）、`completion_provenance.json` 的同四片运行后 stat 与源码 SHA 清单、两次 stat 一致且实际路径为冻结模型权重。stat 只能证明属性未变，不能证明运行时无瞬态权重替换；加载前的独立分片完整 SHA 与这些信息共同构成身份链。proof 绑定运行、验收、源码和每份数组。E1原作者greedy由适配器运行时与冻结E1选点逐项比较；当前记录只留下通过的运行时门和来源，不能声称离线重建greedy本身。KV完整内容只存指纹，并非归档数组；自然臂保留36层逐步缓存长度，强制臂记录33步KV指纹。E1已有DEV混合journal包含预测，身份提取会解析其JSON但不用于新标签或评分。仅3图小样，且适配器额外运行并丢弃greedy，不报告速度、等算力或完整DEV质量结论。
