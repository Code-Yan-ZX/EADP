# Random K256 DEV exploratory scoring plan

This analysis is specified before generation of the full random panel and before opening any of its predictions. It was designed after earlier DEV experiments and is exploratory. It uses the existing fixed 384-question DEV manifest, with 128 questions per task, and all three preselected seeds 20261104, 20261105 and 20261106. A single failed, missing, or unverifiable generation prevents a complete-panel score; no case, answer, or seed may be dropped based on the outcome. Formal no-GT acceptance and independently implemented full-run review must both pass and actually exit before the target predictions or labels are opened.

For each task, score every random answer using both the author metric and an independent implementation, agreeing within 1e-12. Preserve empty answers, EOS and truncations. Compare each seed to accepted EADP K256, P3, DeepStack-on on the same questions. Also calculate the mean of the three random scores *within each question* and compare that mean to the same EADP score; these are not three independent questions. Report all three seed means, the three-seed mean, the EADP mean, task denominators, and each seed-minus-EADP and mean-minus-EADP difference in percentage points.

For every task, resample whole image groups with replacement 10,000 times, seed 20261104, sorted group IDs, using the same resampled indices for every arm. Each resample's score is the question-weighted mean of the sampled groups, as in the prior paired analysis, including duplicate image groups. Report percentile 95% intervals for the four differences and arm means. These intervals cover image-group resampling conditional on the three fixed seeds; they do not estimate uncertainty over an imagined seed population. State the actual NumPy version, group count, all denominators, seed-wise terminal counts and bootstrap method. Multiple comparisons are not corrected and no interval alone establishes a general winner or noninferiority.

Check task, question, group, image and prompt identity, processor metadata, six generation scalars and EOS against accepted references before reading truth; author versus independent scoring must agree for each prediction. Freeze the scorer, its full dependency inventory, source/plan hashes and synthetic edge tests, and obtain independent prelaunch review before scoring. Accept the genuine terminal states, container identities, output hashes and formal/independent review proofs, rather than relying on filename existence. Preserve all attempts and failures.

The random adapter runs the original EADP selector and discards its selected indices; its observed execution time is not random-selector runtime and must not be used for a speed comparison. Same retained K is not proof of equal compute. Results are DEV exploration following previous DEV observations, not confirmation or a final-test result. The full panel archives selected indices and tensor fingerprints, not all high-dimensional tensors, so do not claim complete offline tensor reconstruction.
