# 512 像素、256 视觉 token 的 DEV 完整基线

该探索使用既验固定 DEV 384 题（DocVQA、TextVQA、AI2D 各 128），保留原题、消息、E1 模型生成六标量及 EOS。原始图经作者 expand2square，再在作者 processor 的一次调用中将 fixed resolution 从 1024 暂设为 512 并恢复。每题实际验证 512 路径 grid `[1,32,32]`、merge 2、连续 256 个图像 token、完整非图像 token 和独立重建的三轴位置；必须用实际输入，不把 1024 processor 摘要冒充 512。不得训练、调整阈值或按答案选题。

先只构建身份清单与 384 条 CPU processor 参考，再做无 GPU 同镜像前检。全量模型生成必须在 `rres_k256_execution_v2` 三锚正式及独立结果验收均完成且监督真实退出、完整链另行冻结并独立预审后，才由主控统一调度；本计划本身不授权 GPU、生成或评分。三锚仅支持实际链路身份，不证明其余题目必然成功。

每题使用原作者 512 路径，生成返回后的首次必要 CPU 转换后立即 fsync 完整 token 序列和 prompt 长度，再解码或摘要；逐题留开始、成功或失败日志。实时检查主视觉和三路 DS 的 256 行与对应注入、实际 prefill mask/position/rope delta、每次 36 层 KV 和缓存位置、EOS 或明确截断，恢复局部修改与 hooks。输入或执行异常保留所有已生成原始输出及失败状态，禁止写完成证明；不可忽略失败题、变更题目或缩小分母。完整原始视觉/DS/KV 张量不归档时，只能称在线比较和持久化摘要，不称离线重建。

生成和评分分阶段：384 题完整无 GT 正式验收和独立验收、真实退出通过后，另经评分预审才读取对应 DEV 答案。预定对照为已验 E1 原始高分辨率、EADP K256 DS-on、三个固定 seed 的随机 K256：每题先算随机三 seed 平均，seed 单独全报，不把 seed 当独立题。每任务固定 128 题，按图像组配对重采样 10,000 次、固定 seed 20261104，报告组数、原始任务分母、质量均值、与所有对照的成对百分点差及未校正 95% 百分位区间。作者计分与独立计分逐题一致才接受；保留空答案、EOS 和截断。若展示 −2 pp，仅作后验探索阈值，不能称非劣性或确认性检验；不依据其筛选结果或变更模型。

该面板在看过既有 DEV 和三锚设计之后提出，是后验探索；缩图会改变视觉编码器的计算及图像信息，`K=256` 不意味着与 EADP 或随机剪枝等计算量。此链不计时、不推断硬件收益。来源身份、权重四分片和真实容器/监督完整退出需机器门核验；端点 stat 不能排除瞬态替换。已有 E1 混合 DEV journal 和已验参照预测可能被解析或哈希，仅按计划的身份及对照用途如实记录；新 GT 只在评分阶段打开。
