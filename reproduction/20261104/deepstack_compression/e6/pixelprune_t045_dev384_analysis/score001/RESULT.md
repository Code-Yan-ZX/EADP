DocVQA 的 2 题达到 2,048 token 上限，其余 382 题均 EOS，空答为零；所有 384 题留在分母。阈值选择和本面板是后验 DEV 探索；动态 K 的范围很宽，且 Pixel 在 patch embedding 之后、视觉 Transformer blocks 之前删点，与 EADP 固定 K 的实际计算不同，不能将本表称等预算、等算力或延迟优势。自然 TTFT 和显存尚需另行实测。AI2D 使用固定本地确定性解析规则。高维视觉、DeepStack 和 KV 内容没有全部归档，逐元素身份是运行时检查。
