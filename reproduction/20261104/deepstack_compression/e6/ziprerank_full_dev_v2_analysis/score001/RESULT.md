# ZipRerank 本地适配：384 题 DEV 探索结果

本地 Qwen3-VL-8B、固定 1024 输入、各任务 128 个不同图像的问题。两条 Zip 路线都需本地 RoPE 状态修复；用户文本路线还改变选择器读取的文本范围，包含指令和 AI2D 选项。二者均保留 K=256 的视觉 token，但与 EADP 同 K 不意味着总计算相同。这里不作延迟或作者原版质量结论。

| DEV 任务 | Zip 作者前缀 + RoPE 修复 | Zip 完整用户文本 + RoPE 修复 | EADP P3 / DS-on K256 |
|---|---:|---:|---:|
| DocVQA | 33.48 | 41.29 | 67.85 |
| TextVQA | 53.20 | 44.38 | 80.78 |
| AI2D | 58.59 | 68.75 | 82.03 |

Zip 前缀减 EADP 的配对差分别为 −34.36 [−44.40, −24.03]、−27.58 [−36.64, −19.06]、−23.44 [−32.03, −15.63] 百分点；用户文本减 EADP 分别为 −26.56 [−36.49, −16.33]、−36.41 [−45.23, −27.42]、−13.28 [−20.31, −6.25]。用户文本减前缀分别为 +7.80 [−1.30, +16.79]、−8.83 [−18.20, +0.62]、+10.16 [+2.34, +18.75]。区间为按图像分组配对 10,000 次 percentile bootstrap、seed 20261104，均为未多重校正的 DEV 探索结果。

两条 Zip 共 768 次自然生成均以 EOS 结束，空答和截断均为 0，完整 384 题分母保留。输出及输入身份的无标签验收见 `../../ziprerank_full_dev_v2_accept/verification001.json` 与 `../../../e1_independent_review/zip_full_dev_v2_result_review.json`；逐题得分、任务汇总与 bootstrap 分别为本目录 `scores.jsonl` 和 `analysis.json`，并经 `../../../e1_independent_review/zip_full_dev_v2_scores_review.json` 独立复算。仅 E1 已归档的六项生成标量与 EOS 逐题核同，其他生成配置已记录但不声称完全同一；高维视觉、DS、KV 内容未完整归档，逐元素相等是在线检查。AI2D 使用固定本地确定性解析规则。这些面板是开发证据，不是确认集或最终检验。
