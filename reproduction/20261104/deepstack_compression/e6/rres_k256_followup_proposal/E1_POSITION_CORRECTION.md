# E1 P1-D1 参照解释更正

`E1 full` 中的 full 表示完整 384 题面板，并不表示全视觉 token。核对作者适配 `e1/position_adapter.py` 的 FourArm 合同，P1-D1 实际同样保留 K=256。后续必须称其为“E1 P1-D1（K256）”或“E1 完整面板的 P1-D1”，不得称无压缩。

先前已冻结并随 GPU 运行快照保存的 `e6/rres_k256_dev384_exec/PLAN_delta002.md` 与 `PLAN_delta003.md` 曾误称“无压缩 E1”，原文和快照为保全审计链不可覆盖；该错误是对参照含义的文字描述，须在后续报告及引用中以本更正为准。R-res 对 EADP P3-D1 的既验逐题比较和数值不因命名更正而改变。此更正不声明 P1-D1 与 P3-D1 在位置或计算上相同。
