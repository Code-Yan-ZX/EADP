# R-res 与 EADP 的逐题差异：只读描述方案

此分析在 384 题完整结果和独立评分复算后制定，是后验 DEV 描述。只读已验收 `rres_k256_full_analysis_v2/score001/scores.jsonl` 的题目/图组身份及已经计算好的 R-res、EADP 分数，并与固定384输入清单逐项绑定；该混合文件也含已生成预测文本，解析文件时会打开这些既有预测，但不使用或输出文本，不重新打开GT原始文件，不训练模型、不调整阈值、不选择测题。若评分、独立审查、真实监督或来源哈希不匹配，在读取分数前拒绝。

每任务完整128题，任务内图组级为单位报告 R-res 得分高/相等/低的题数、各类差值总和、任务平均配对差和每题差值；DocVQA 的 ANLS 是连续分数，不能把所有分数变化直接称对/错或 rescue/break。重复10,000次图组配对bootstrap估计差值区间，固定 seed 20261104；结果为未经多重比较校正的探索描述，不证明原因、预测能力或非劣性。必要的未来图片尺度/文本密度分析应独立事先固定特征和边界，按全部图报告；不得按本轮答案训练分流或把后验关联称机制。

正式分析应另冻结本目录来源、测试、输入证明和输出路径并经独立预审；当前是CPU合同与测试，未运行正式分析。已冻结旧结果中 `e1_full` 指完整384面板的 E1 P1-D1 K256，绝非未压缩，不能用该误名解释本分析。
