# R-res 三锚自然生成执行合同草稿

本目录是受控执行代码草稿，不是 GPU 授权。固定 DocVQA 16539、TextVQA 39421、AI2D 368100，沿用 E1 图片、消息、作者 `_build_messages` 和自然生成六项标量/EOS，512 正方形处理通过作者函数短暂 scoped 参数覆盖，退出恢复 1024；从已验 E1 混合预测记录仅读对应身份和生成控制，不读 GT、不评分。三图预先锁定，结果不能用来代表总体质量、性能或等算力。K256 指实际 processor/视觉合并后的 token 数，视觉塔输入网格和计算不同于高分辨率 EADP K256。

实际 worker 在模型生成前校验 512 processor 四张量及 `get_rope_index` 与同镜像 CPU 证明相同；要求模型 bf16/FA2；在线观测视觉主路与三路 DS 实际各256行，DS 注入与视觉输出逐元素一致，主视觉写入正确位置，mask 和三轴 mRoPE 与 CPU 参考一致；保存每步36层KV物理长度/位置与实际P3 delta。作者自然生成完整raw sequence在解码、裁剪和检查之前落盘并 fsync；失败保留 raw/失败日志及未执行分母。原分辨率、方法及 hooks 必须恢复。完整浮点视觉/DS/KV未归档，结果只能报告在线检查及摘要。

拟定单容器、单模型三个连续任务，上限内层3600秒、外层3720秒、清理宽限120秒，起始须有完整期限余量、独占 GPU、先有真实 noGPU 结果及独审，且源码/计划、预冻 formal 及 GPU 前独审完成。真实GPU由主控安排。`gpu_gate.admit_gpu` 缺任一实际证明即拒绝；现尚未冻结GPU计划和独审，不得启动。受监督 source snapshot 是运行后取得，端点hash不足排除运行中短暂修改。

CPU-only 和已执行的 processor 预检只验证输入与位置，尚不证明 GPU 实际视觉/DS或本 worker 兼容；需进一步实际同镜像无GPU验证执行入口并独审，之后再冻结 GPU 计划/验收与最终审核。存量 DEV 预测仅为身份/EOS控制读取；不使用答案或任何 GT。
