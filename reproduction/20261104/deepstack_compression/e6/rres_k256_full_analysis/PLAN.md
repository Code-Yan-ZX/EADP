# R-res 512/K256：完整 DEV 配对评分计划

本方案在低分辨率384题输出生成和读取前制定，但在观察其他 DEV 实验与三锚诊断之后，属于事后探索；不是独立确认实验。只在384题自然生成完整、正式无GT验收及独立无GT复核均实际退出0并通过后，才可打开本面板任何预测、已有评分内容或DEV标签；任一缺失、重复、故障、身份错配阻断整个评分，不替换/丢弃题目。既有参考工件在预检阶段仅可为SHA打开，不解析其预测或评分内容。

每任务128题（DocVQA、TextVQA、AI2D），严格按任务、题ID、图组、图像字节与消息哈希配对此前已验 E1 EADP K256 P3/DeepStack-on 、已验三seed K256随机自然生成，以及既验未压缩 E1 P1/DeepStack-on（额外参照）。低分辨率实际 processor 必须达到512px、256视觉token及对应网格/位置并通过完整双重无GT验收；E1和随机为原1024视觉输入后选择256，两者processor不同不得要求字节相同或宣称等算力。各臂均核同图同提示、已验输入来源、贪心生成条件六参数与EOS；保留各臂EOS、截断和空答。

对目标面板用与已验E1相同的官方作者与独立评分器；每题两者须有限且差≤1e-12。每任务分别以原生 XLSX 进行目标预测往返以匹配已有官方评分的类型转换，保留空答及原始token。参考每题使用独立验收并绑定源输出的 E1 分数及随机三seed分数，核有限和官方/独立一致。三seed先在每题内求均值，不把它们当作独立题目。输出每任务各臂均分及95%区间、R-res减EADP、减未压缩E1、减每个随机seed、减每题三seed均值的配对差和区间，同时列所有分母、EOS/截断/空答。

每任务按排序后的图组为单位抽样10,000次、PCG64 seed 20261104，同一次抽样供各臂及所有对比使用，组内题目等权并保留多题组。报告完整结果，不按差异或通过情况筛题；区间为未作多重校正的探索结果，不用于单独确立方法、训练阈值或做非劣性结论。相同K不代表相同计算量；随机adapter还执行并丢弃EADP greedy，其耗时不可视为随机选择器速度。此前观察过DEV，这不是FINAL。

门控必须绑定评分计划、评分代码/版本、纯合成测试与独立预审；以及未来R-res完整生成的真实容器/监督退出、源快照、正式与独立证明及所有逐题文件SHA。对先前E1和随机完整推理及评分证明、各监督真实退出、各已验记录和评分SHA进行同样绑定。任何正式/独审链缺失，在目标预测或GT访问前失败。现阶段只执行合成测试和无GT源/门检查，不运行GPU、不打开新目标预测或标签。
