# R-res / EADP 三锚真实模型前置身份诊断

这是在已看 DEV 分数后设计的实现校验，不用于推断质量、训练或选择图片。取现有冻结32测量图中各任务的首题：DocVQA 64588、TextVQA 36511、AI2D 207406；每题两臂，共6次完整自然生成。图像、消息、处理器身份和各自既验输出分别绑定已验 R-res 384 与 E4 K256 P3-D1；运行不读新GT。

每臂必须实际经过未来测量调用器及其首token停止观察和HF配置记录。记录显式kwargs结构与真实 `_prepare_generation_config` 结果，对每题从实际processor读取四个tensor、R-res视觉256、EADP原视觉1024与作者选点256；独立核输入及P3位置、三路deepstack及36层KV长度/位置，记录自然EOS、完整token并逐token对各臂自己的既验记录。高维视觉/KV若仅保存哈希则不可声称事后可重建原张量；诊断hook和同步会扰动执行，不解释时延。

应在单独目录实现有界控制器、即时原始输出与异常留证、来源计划、无GPU导入前检、GPU前独审、运行后正式及独立验收。EADP的诊断观察应包装实际 `BudgetLightAdapter` 的状态与前向，而不是嵌套第二套会改变行为的适配器；R-res沿已验 Capture/DecodeObserver 接口验证。任一输入身份、配置或完整同臂输出不符时完整保留证据且不得放行后续正式计时，不得挑选题目或解释为普遍失败。三锚通过只是运行身份证据，不能自动证明其余题或加速。

控制器须以同步落盘的阶段与每题 started/completed/failed 进度作为停滞信号，模型加载和单条2048 token自然生成必须有适当宽限；对进程组和真实容器设置单项及外层硬限，超时后停/杀并复核容器与GPU PID归属，失败和部分结果不覆盖。具体秒数须在冻结前结合既有真实运行时长确定，不能在运行后更改；不得靠背景45分钟健康日志代替退出控制。

当前文档为准备稿，尚无可执行三锚GPU入口或GPU许可。实际设备由主控调度；先完成并独审当前同镜像无GPU前检，再冻结此诊断的代码和正式验收。
