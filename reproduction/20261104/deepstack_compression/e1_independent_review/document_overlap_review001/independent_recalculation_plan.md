# Independent document-overlap recomputation

Run only after the full training audit and its independent audit have each completed successfully and their supervisor processes have actually exited. Before opening either the full audit rows or the diagnostic, validate each proof's source and input hashes and its supervisor command, matching process identity, clean exit and empty process group. Bind the audit rows to both proofs, bind the evaluation manifest to the frozen audit protocol and manifest summary, and bind the DocVQA page-identity semantics proof. Abort on any missing or changed evidence.

Use a separately implemented streaming pass over the completed rows and evaluation metadata only. Reject non-string or blank document identifiers, unknown split names, malformed DocVQA paths, duplicate question IDs, unexpected row totals, and an evaluation count inconsistent with the frozen manifest. Compare the observed total and each split count with the independently accepted audit. Never load question or answer values or prediction files.

Independently construct sets of distinct document identifiers for all source rows, fit, validation, excluded-evaluation rows, and the DocVQA evaluation manifest. Report all-source and eligible (fit plus validation) row counts separately, and for each split report both the number of rows whose document is in evaluation and the number of distinct documents in that intersection. Compute `fit ∩ validation`, `fit ∩ evaluation`, `validation ∩ evaluation`, their three-way intersection and optionally the distinct union of these risk sets. State explicitly that an excluded row is not an eligible training row. Compare every reported field with the revised diagnostic, not just a combined total.

The result concerns exact document-ID equality, not semantic similarity or proven duplicates; eval document metadata covers DocVQA only. Preserve the post-hoc nature of this diagnostic and do not change or approve any existing split. This diagnostic provides evidence for a future training decision; it does not itself authorize training.

Bind all input proof hashes, supervisor start and terminal records, source hashes, code hash, output counts, and actual review supervisor clean exit. Exercise synthetic cases covering a one-split evaluation overlap, unrelated fit-validation overlap, three-way overlap, exclusion-only documents, duplicate rows or identifiers, malformed IDs, unknown split, and mismatched source/proof hashes before running on completed data.
