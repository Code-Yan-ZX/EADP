# M3 第二批 DEV：准备阶段

首批 128 题之后，按原来的 `SHA256(20261104|group_id)` 顺序，从未出现在首批的 E1 DEV 图像组中再取 DocVQA 64、TextVQA 32、AI2D 32。样本冻结发生在首批得分和独立复核之后；选择只用已冻结输入清单，不使用分数、预测或新标签。两批必须分别报告，这是第二次探索性查看，不能作为一次预先指定的正式检验。第二批所有图像组不用于学生确认。

继续使用原样的 full-1024 teacher、首个参考答案目标、四路 utility、候选规则和 Python 3.10 实现；每题 r=8/16 × MAIN/MULTI/RANDOM 各一个赢家，复用同题已验收 E1 基线之前必须逐题核输入、实际 prefill 和首 logits。每题最多 49 次去重 teacher 候选评估，另有一次四路梯度，以及 6 次真实自然生成；第二批最多 6,272 次候选评估、128 次梯度、768 次新增生成。先完成所有 128 题及正式和独立无评分验收，再读取第二批 DEV 答案计算生成质量。r8 的未决区间是本次扩样动机；首批 ALL 的 r16 MULTI−MAIN 上界已低于预设 1pp，不能将其作为多流方向支持。

首批实际 supervisor 耗时 1,351.29 秒（约 22.5 分钟，含加载和退出），记录 6,259 次去重 teacher 评估与 768 次生成，运行目录约 40 MB。这是单次实测，不保证第二批时长。待实现并审查的第二批独立 launcher 可先采用内层 7,200 秒、外层 7,380 秒、每小时健康快照、进度停滞停止以及不晚于用户三天绝对截止的条件；GPU 独占、模型前完整无 GPU 容器预检、真实停止/清理及剩余时间/磁盘门都必须重新验证。`runtime_worker.py` 是从首批实现复制并改为第二批样本的草稿，`batch_gate.py` 在任何文件读取、模型加载或预检前无条件拒绝；它尚无第二批 GPU 运行许可，不能复用首批的 admission proof 作为第二批许可。
